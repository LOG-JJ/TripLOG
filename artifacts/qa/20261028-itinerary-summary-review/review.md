# 일정 요약의 접힌 카드 검토

검토일: 2026-10-28 (Asia/Seoul)
대상: 운영 TripLOG 일정 요약. 기존 편집창을 보존하고 별도 임시 탭에서 확인. 코드 및 여행 데이터 변경 없음.

1. 접힌 날짜 카드: 정상 표시되지만 Day/날짜, 메타데이터, 긴 화살표 동선, 미입력 안내가 비슷한 크기와 명도로 이어져 훑어보기 어렵다. 현재 8~13개 일정이 한두 줄의 텍스트 체인으로 축약된다. 근거: 01-collapsed-summary.png, 01-collapsed-card.png.
2. Day 2 상세 펼치기: 정상 동작. 시간과 컬러 점, 장소가 분리된 세로 목록에서 정보 위계가 더 명확하다. 근거: 02-expanded-summary.png.

권장 방향: 흰색 하루 요약 카드에 날짜 배지, 시간 범위와 일정 수, 컬러 테마 아이콘이 있는 방문지 최대 3개와 나머지 개수, 명확한 상세 일정 보기 동작을 둔다. 반복되는 숙소는 본문 방문지 미리보기와 구분해 보조 정보로 표시한다. 이동 시간은 기록이 불완전하면 확인된 시간과 미입력 수를 함께 표현한다. 연한 프로젝트 포인트색은 배지와 아이콘에만 집중하고 기존 진한 윤곽과 작은 그림자를 사용한다.

접근성 검토 범위: 작은 연회색 텍스트와 펼치기 제어의 구분은 개선 대상으로 보이지만 명도 대비 수치, 키보드 흐름, 스크린리더, 모바일 폭은 이번 검토에서 검증하지 않았다.

캡처: cua_repl로 연결한 in-app browser, 탭 스크린샷. 최초 getScreenshot에서 나온 다른 화면과 잘린 상세 카드 캡처는 근거로 채택하지 않고 정상 캡처로 대체했다.
