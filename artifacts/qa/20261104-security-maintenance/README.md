# 보안 점검·개발 구조 정리

2026-11-04 · Asia/Seoul. 로컬 코드·파일 구성 점검과 수정입니다. 커밋·푸시·운영 배포, 운영 여행 데이터 변경, DB 마이그레이션과 Edge 배포는 실행하지 않았습니다.

| 항목 | 확인한 상태와 조치 |
| --- | --- |

| 브라우저 스크립트 | CSP 추가. 진입·복구 인라인 코드를 `src/entry/`로 분리하고 국가 국기 fallback을 이벤트 리스너로 변경. |

이번 점검에서 실제 운영 키 유출이나 재현된 계정 간 접근 결함을 확인한 것은 아닙니다. 확인된 방어 공백과 우발적인 파일 노출 가능성을 줄이는 보강입니다. 로직 전체에 취약점이 없다는 보증은 아닙니다.

## 폴더 정리

- 테스트·실행 목록·fixture·테스트 지원 파일 105개를 `scripts/`에서 `tests/`로 이동.
- 전체 캡처·PDF·실행 뷰어·진단 자료 1,316개를 Git에서 제외하는 `artifacts/tmp/`로 이동.
- 디자인 자료 안의 완료된 QA 56개를 `artifacts/qa/`로 이동.
- 합계 1,477개 파일, 이동 당시 104,042,180 bytes. 모든 목적지 파일이 존재하며 이미지 바이트는 변경하지 않음.
- 원본 생성 프롬프트·출처·입력 이미지·과거 감사 JSON은 유지. 파일 위치는 [전체 이동·해시 기록](../../relocations-20261104.json)에서 확인.
- 문서 링크·require·제작 도구 경로를 갱신. [개발 안내](../../../docs/development.md), [보안 기준](../../../docs/security.md), [산출물 기준](../../README.md) 추가·갱신.

`tests/source-integrity-regression.js`는 앱뿐 아니라 개발 도구와 테스트의 JavaScript 구문도 검사합니다. 산출물 검사는 디자인 영역의 브라우저 출력 폴더, 영구 보관 영역의 PDF·ZIP·로그와 QA용 실행 스크립트도 검출합니다.

## 검증

- `dev test --suite all --json`: 통과. CLI 222개 프로세스 단언과 SQL·파일·권한·충돌·재시도·백업·배포 검사, 터미널 회귀 포함.
- `dev test --suite source --json`: 최종 수정 후 통과. 모듈·스타일·브라우저 등록·산출물 배치·보안 검사 포함.
- `dev test --suite edge --json`: 4개 통과. CI 고정 버전 Deno 2.9.6을 작업 임시 폴더에 설치해 실행.
- 실제 브라우저 보안 검사: 주입한 인라인 스크립트·이벤트 실행 차단, 로컬 로그인 SDK 로드, 국기 이미지 fallback과 OCR Worker·WebAssembly 정상 동작. 실제 OCR 결과 `TOTAL 12345`.
- 전체 목적지 검사: 635곳 × 320/390/599/1440px = 2,540조합 통과. 이미지 변형·투명도·좌우 배치·텍스트·데이터 보존 검사 포함.
- 기존 예약 요약 검사와 스크롤 검사의 오래된 화면 접근을 현재 예약 지갑 페이지·준비물 시트에 맞춤. 스크롤 임계값은 실제 남은 스크롤 범위를 반영.
- `dev build --json`: 통과. 배포 파일 1,642개를 로컬 원본과 바이트 대조. 개발 자료·서버 코드 배포 제외 확인.
- 보관 vendor 체크섬: OCR 15개, Leaflet 8개 모두 일치.
- `dev artifacts --json`, `git diff --check`: 통과. 변경 문서의 로컬 링크와 옮긴 JavaScript의 상대 require 경로 점검.

브라우저 전체 결과와 최종 지문은 [기계 판독 검증 요약](verification.json)에 기록합니다. 전체 실행 로그·캡처·임시 런타임은 `artifacts/tmp/20261104-security-maintenance/`에 있습니다. 완료된 구간을 불필요하게 다시 생성하지 않고 실패한 검사와 남은 검사를 이어 실행했습니다.

## 확인 범위

운영 Supabase의 실제 정책 적용 상태, 운영 Edge·호스팅 응답 헤더와 배포 완료 여부는 확인하지 않았습니다. 외부 Google Maps API의 실제 키·실계정 인증, HEIC 및 모든 OCR 언어·실기기 Safari/모바일 조합도 이번 격리 검증 범위를 벗어납니다. 로컬 빌드·테스트 성공을 운영 반영으로 보고하지 않습니다.
