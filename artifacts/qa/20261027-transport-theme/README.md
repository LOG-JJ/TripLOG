# 이동 테마의 공통 일정 편집

2026-10-27. 로컬 수정·검증 완료. 운영 배포 전입니다.

일정 편집창의 교통예약 필드셋과 전용 필드 바인딩을 제거했습니다. 이동 테마도 다른 테마와 같은 장소·소분류·시작/종료·메모 입력을 사용합니다. 선택만으로 예약 이름이나 `transportReservation`을 생성하지 않습니다. 기존 예약의 종류·노선·도착일·예약번호·연결 ID는 일정 편집에서 보존하고, 예약 지갑에서는 기존처럼 편집할 수 있습니다.
