# 즉시 일정 복사·숙박일 기본 일정·흰색 바탕

사용자 요청: 복사 버튼은 편집창 없이 즉시 복사하고, 숙소 예약의 숙박일에 일정을 한 개씩 자동 추가하며, 첨부 메뉴와 앱의 크림색·연노란 바탕을 메인 흰색으로 통일한다. 추가 답변에 따라 노란 주요 버튼은 유지한다.

## 최종 동작

- 일정 복사: 같은 날짜·시간의 독립적인 새 항목을 즉시 저장한다. 장소·주소·메모·바우처·좌표·교통 예약 입력값을 보존한다. 원본의 예약 연결·입력 이동 구간·교통비 소유권은 복제하지 않는다. 수동 순서에서는 원본 다음에 삽입한다. 저장 중 이중 클릭은 한 번만 처리하며 실패 시 복사본을 화면에서 되돌리고 기존 저장 복구 경로를 안내한다. 원본·다른 일정·지출은 보존한다.
- 숙소 기본 일정: 체크인일부터 체크아웃 전날까지, 여행 기간 안의 숙박일에 기본 숙소가 표시된다. 신규 예약은 기존 저장 로직을 쓰고, 이전 예약의 빠진 일차는 일정 화면 진입 시 보충·저장한다. 직접 등록한 예약과 사전구매 숙소 모두 지원한다. 이미 연결된 숙소와 이름·주소·예약번호가 일치하는 독립적인 수동 숙소는 보존하며 해당 날짜를 중복 생성하지 않는다. 날짜별 메모·도착시간은 유지하고 결제 지출은 늘리지 않는다.
- 기본 숙소 ID는 예약 ID·숙박일로 결정한다. 같은 공유 여행의 기기별 로컬 여행 ID가 달라도 같은 ID가 나온다. 이미 같은 ID를 다른 일정이 사용하면 충돌하지 않는 ID를 사용한다. 반복 렌더·새로고침으로 중복되지 않으며 보기 전용·보관·로그인 전 상태에서는 자동 쓰기를 하지 않는다. 저장 실패는 복구 안내를 표시하고 반복 저장 루프를 막는다.
- 흰색 바탕: 메인과 같은 `--tl-surface: #fff`를 사용한다. 메뉴·내 여행·예약 지갑·오늘/점검/도구·입력/상세 영역 등의 크림색·연노란 바탕을 통일했다. 노란 주요 버튼과 선택·드래그·일시적인 조작 피드백, 분류 색상과 오류 의미 색은 유지한다. 세부 색 변경은 `surface-changes.json`에 있다.

## 검증 환경

Browser 플러그인을 사용할 수 없어 기존 Playwright/Edge 격리 fixture를 사용했다. 로컬 서버와 가상 계정·여행으로 검증했고 실제 사용자 브라우저 저장소·운영 여행 데이터는 수정하지 않았다. 외부 지도·API 요청은 차단하거나 fixture 응답으로 대체했다. 실제 iPhone/Safari는 별도 검증하지 않았다.
