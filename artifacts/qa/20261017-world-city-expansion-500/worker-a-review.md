# Worker A 세계 도시 일러스트 검증

2026-10-17 기준으로 담당 62개 도시의 PC·모바일 이미지 124장을 완료했다. Core 단계는 55개 도시 110장, 국가·거주 지역 보완 단계는 7개 도시 14장이다. 마지막 보완 대상인 코코스 제도 웨스트아일랜드, 토켈라우 누쿠노누, 레위니옹 생드니는 호출 전에 root에 이관했으며 이 보고서의 생성 수에 포함하지 않는다.

## 생성·보관

- 124개 활성 이미지는 모두 built-in ImageGen의 독립적인 T2I 호출에서 생성했다. 입력 이미지와 연쇄 I2I는 사용하지 않았다.
- 각 호출이 반환한 정확한 PNG 경로와 호출 직전 시각을 기록했다. 반환 원본과 `artifacts/design/20261017-world-city-expansion-500/assets-original/` 보존본의 SHA256이 일치한다.
- 활성 원본 경로 124개가 모두 고유하다. PC 자산은 800×480, 모바일 자산은 480×600이며, 전부 투명 알파 채널이 있다.
- Job JSON, 별도 프롬프트 파일, 원본 메타데이터의 최종 프롬프트와 SHA256이 일치한다. 활성 WebP의 SHA256도 각 `.asset.json`과 일치한다.
- 최종 수치는 `worker-a-final-validation.json`에 남겼다. 전체 작업의 최종 합본 감사 결과는 root가 별도로 관리한다.

## 시각 검토와 보완

Core의 10개 접촉 시트에서 55개 도시의 PC·모바일 쌍을 모두 검토했다. 보완 단계의 2개 접촉 시트에서 7개 도시 쌍을 검토했다. 주요 피사체의 정체성, 두 방향의 일관성, 전체 실루엣, 상단·우측 잘림과 투명 배경을 확인했다.

Core에서 11장을 다시 생성했다. 안도라라베야는 Casa de la Vall의 소박한 석조 관저와 작은 부속 망루로 맞추고 불필요한 하천·다리를 제거했다. 로조는 실제 박물관의 황토색 벽, 붉은 셔터, 흰 발코니와 시계 박공으로 통일했다. 브라자빌은 생트안 대성당의 가파른 녹색 곡면 지붕과 현대식 첨탑으로 바로잡았다. 팔레르모·밤베르크·세고비아·히메지는 주요 지붕 끝, 십자가, 수로교 끝부분의 여백을 확보했다. 이전 66개 파일은 SHA256 대조 후 `revisions/worker-a-r2-architecture-framing/`에 보존했다.

브라자빌 모바일의 거의 투명한 하단 여백은 원본 PNG를 유지한 기술 변환으로 보정했다. 이전 WebP와 메타데이터는 `revisions/worker-a-r3-alpha-edge/`에 보존했고 실제 320·390px 헤더에서 보이는 하단·오른쪽 간격이 모두 0px임을 확인했다.

보완 단계에서 산후안과 콕번타운 4장을 다시 생성했다. 산후안은 성벽 오른쪽 끝과 초소가 모두 프레임 안에 들어오도록 구도를 넓혔다. 콕번타운은 실제 Guinep House의 흰 벽, 붉은 금속 지붕, 녹색 셔터와 그늘진 베란다를 반영했다. 이전 24개 파일은 `revisions/worker-a-coverage-r2-framing-and-museum/`에 보존했다. 모든 보완도 새 T2I 호출이며 이미지 입력은 없다.

## 실제 헤더와 데이터 회귀

- 보완 7개 도시를 320·390·1440px에서 렌더링한 21개 조합이 통과했다. 반응형 이미지 선택, 투명도, 정보와 그림의 좌우 배치, 넘침, 실제 그림의 오른쪽·하단 연결, 기존 여행 데이터 불변을 검사했다.
- 산후안·콕번타운의 320px 및 1440px 최종 캡처 4장을 직접 확인했으며 이 폴더의 `worker-a-pr-san-juan-*` 및 `worker-a-tc-cockburn-town-*` 파일에 보존했다.
- `node scripts/destination-scenes-regression.js --skip-assets`: 635개 전용 목적지(국내 95, 해외 540), 원본 395개 객체 불변, 필수 국가·거주 지역 누락 0, 250개 국가 선택기 이름·별칭, 모호함·미지정·복수·지역 폴백 통과. 이 명령의 파일 존재 검사는 최종 합본 이미지 감사와 분리했다.
- `node scripts/country-search-regression.js`: 250개 영어 국가명, 한글·영문·코드 별칭, 대소문자·문장부호·부분 검색·잘못된 입력 통과.
- 담당 런타임 및 회귀 파일의 `git diff --check` 통과.

실행 로그·전체 접촉 시트·전체 캡처는 Git 제외 경로인 `artifacts/tmp/20261017-world-city-expansion-500/`에 둔다. 이 보고서는 로컬 생성·검증 결과이며 Git 푸시 또는 운영 자동 배포 완료를 뜻하지 않는다.
