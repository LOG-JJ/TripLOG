# 지출 항목 순서 변경 검증

2026-10-26 요청: 지출 기록의 항목 순서를 변경하고, 이동 버튼은 일정과 같은 손잡이 하나 및 같은 라이브러리·컴포넌트로 구현한다.

## 최종 동작

기본순에서 각 지출 오른쪽의 점 여섯 개 손잡이를 바로 잡아 이동한다. PC 마우스, 모바일 터치, 손잡이에 포커스를 둔 `Alt+↑/↓`를 지원한다. 변경한 순서는 자동 저장되며 새로고침 후에도 유지된다. 검색·카테고리·사전구매 탭으로 일부 항목만 표시한 경우 보이는 항목을 기준으로 이동하고, 다른 항목의 순서와 내용은 유지한다. 새 지출은 수동 순서 뒤에 표시한다.

기존 금액순·최신순 등은 수동 순서를 지우지 않는다. 별도 정렬 중에는 이동 손잡이를 숨기고 기본순 선택 안내를 표시한다. 읽기 전용 여행과 이동할 다른 항목이 없는 목록에는 손잡이를 표시하지 않는다. 저장 실패를 성공으로 표시하지 않으며 기존 저장 상태의 복구 기능으로 연결한다.

## 공통 컴포넌트

- 라이브러리: 기존 번들 `@dnd-kit/dom 0.5.1`을 그대로 사용한다.
- `src/app/ui/sortable-list.js`: 일정과 지출이 실제로 공유하는 목록 드래그 엔진 및 손잡이 마크업이다. 포인터 센서, 정렬, 피드백, 자동 스크롤, 취소, 포커스·키보드·접근성 안내를 공통 처리한다.
- `src/app/features/itinerary/dnd-drag.js`: 기존 일정 엔진을 위 컴포넌트의 설정으로 연결한다. 일정 연결선 및 착지 애니메이션은 기존 함수를 사용한다.
- `src/app/features/expenses/expense-workspace.js`: 같은 컴포넌트를 지출 목록에 연결한다. 별도 순서 변경 모드나 위·아래 버튼을 추가하지 않는다.
- `src/styles/itinerary-drag.css`: 두 화면에 같은 44×44px 손잡이 스타일을 적용한다. 실제 렌더링에서 크기, 색, 배경, 모서리, 터치 동작이 같은지 비교했다.
- `src/app/shared/expense-order.js`: 독립적인 `expenseOrder` 값으로 순서를 저장한다. 날짜·금액·예약 정보·연결 일정과 분리하며 기존 동기화 데이터 계약을 사용한다.
- CLI의 지출 이동·목록도 같은 순서 모델을 사용한다. JSON 백업과 기존 로컬·서버 동기화 경로에서 순서를 보존한다.

## 검증

격리된 테스트 계정과 가상 여행으로 로컬 Playwright/Edge에서 실행했다. Browser 플러그인이 제공되지 않아 프로젝트의 기존 Playwright 도우미를 사용했다. 외부 요청 및 서비스 워커는 테스트에서 차단했다. 이로 인해 발생한 네트워크·서비스 워커 경고는 `browser-result.json`의 `fixtureWarnings`에 분리했다. 앱 런타임 오류와 그 외 콘솔 오류는 없다. 실제 사용자 계정·여행 데이터는 수정하지 않았다.
