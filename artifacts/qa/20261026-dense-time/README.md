# 시간 선택창 글씨·표시 밀도 조정

사용자 추가 요청: 글씨 크기도 줄여 한 번에 더 많은 내용이 보이도록 한다. 앞서 줄인 공통 시간 선택창에 적용했다.

- 시간·분 숫자: 16px → 14px. 제목과 하단 버튼: 12px → 11px.
- 휠 표시: 각각 3줄 → 5줄. 선택값 위아래 두 값이 보이며 가장 바깥쪽 행도 클릭할 수 있다.
- 행 높이: PC 28px → 18px, 터치 32px → 20px. 여백과 버튼 높이도 함께 축소했다.
- 입력칸에 맞추는 폭은 유지한다. 모바일 390px에서 170×180px → 170×174px, PC 1440px에서 169×166px → 169×162px이다. 320px에서는 152×174px, 가로 640px에서는 224×174px이다.
- 터치에서 숫자를 직접 편집할 때는 기존 16px를 유지해 iOS 입력 확대를 방지한다. 일반 휠 숫자는 14px다.

## 검증

격리된 로컬 `/Travel?page=itinerary` → 일정 추가 → 시간 선택창 → 5줄 표시·바깥 행 클릭 → 스크롤·직접 입력 → 확인·저장·새로고침 경로를 확인했다. 기존 Browser 플러그인이 없어 프로젝트 Playwright/Edge 도우미를 사용했다. 실제 사용자 여행 데이터는 수정하지 않았다.

1440×1100, 터치 390×844·320×844·640×360에서 캡처했다. 페이지 제목·초기화·편집창 표시·오류 오버레이 부재를 확인했고 런타임 오류는 없다. 콘솔의 외부 요청 실패와 서비스 워커 차단 경고는 테스트 격리 설정에서 발생했다. 실제 모바일 기기·Safari의 OS 키보드는 별도 검증하지 않았다.

대표 캡처와 SHA256은 `verification.json`, 실제 크기와 화면 상태는 `after-metrics.json`, 열린 상태의 크기 변경 결과는 `size-checks.json`에 있다. 변경 전은 바로 앞의 3줄 버전이며, 더 큰 원래 화면과의 비교는 `../20261026-compact-time/`에 보존한다.
