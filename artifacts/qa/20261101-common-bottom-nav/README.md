# 하단바 5개 항목 공통 규격 적용

2026-11-01 · Asia/Seoul

사용자는 여행 아이콘만 작게 만드는 개별 보정을 거부하고 PC·모바일의 아이콘·글자·간격을 동일한 규칙으로 맞추도록 요청했다. 직전의 여행 전용 font-size 20px과 별도 grid 규칙은 제거했다.

## 공통 구현

- 기존 Phosphor의 집·달력·캐리어·지갑·차트 원본 모양을 유지한다. 5개 모두 원본 font glyph path와 실제 bounds를 같은 코드로 SVG로 추출했다. 메뉴별 scale·translate·font-size·offset을 지정하지 않는다. 폰트 내부 여백 대신 원본 그림의 bounds를 viewBox로 사용한다. [원본·재생성 기록](../../design/20261101-common-bottom-nav/README.md).
- 동일한 CSS mask 렌더러를 사용한다. 아이콘 영역은 28×24px이고 실제 그림을 같은 contain 규칙으로 맞춘다. 서로 다른 아이콘을 정사각형으로 늘이거나 원본 모양을 변형하지 않는다.
- 각 버튼은 같은 grid: 24px 아이콘 행 / 4px 간격 / 16px 글자 행. 글자는 모두 12px·600이며 선택 상태에서도 굵기나 크기가 바뀌지 않는다. 선택은 기존 색상·배경·밑줄로 구분한다.
- 하단바는 5등분 열과 좌우 4px 여백을 사용한다. 메인 화면과 모바일 일정 편집창 모두 같은 규칙이다. PC 일정 편집창에서 하단바가 숨겨지는 기존 동작은 유지했다.
- 새 아이콘 라이브러리·런타임 의존성은 없다. 변환한 실제 사용 SVG 5개만 앱 자산에 포함한다. 런타임과 npm build는 Python을 요구하지 않는다.

## 실제 화면과 측정

[수정 전/후](comparison.png). 수정 전은 직전 여행 개별 축소 상태의 같은 390px 캡처이며, 수정 후에는 5개 모두 공통 렌더링을 적용했다.

- 모바일: [320px](nav-320-1.png), [390px](nav-390-1.png).
- 전환 구간: [760px](nav-760-1.png), [850px](nav-850-1.png).
- PC: [1440px / DPR 1](nav-1440-1.png), [1440px / DPR 1.5](nav-1440-1.5.png).
- 모바일 일정 편집창: [320px](editor-nav-320-1.png), [390px](editor-nav-390-1.png).

실제 캡처의 각 아이콘 영역에서 어두운 픽셀(max(R,G,B)<180)을 측정했다. 6개 화면 조건 전체에서 5개 아이콘의 실제 높이는 23.33~24 CSS px, 같은 화면의 상단 차이는 1 CSS px 이하이고, 아이콘 칸과 글자 행의 간격은 모두 4px다. DPR 1.5의 래스터 경계 차이는 CSS px로 환산했다. [실제 픽셀 측정](paint-bounds.json), [DOM·공통 폰트·간격·편집창 측정](layout.json).

메뉴별 예외 크기 보정이 없으며 기존 20px 캐리어 축소를 유지하지 않는다. 기존 아이콘 종류와 형태는 동일하고 5개가 공통 24px 높이로 보인다. 같은 그림 높이에서도 캐리어의 가로폭이 좁은 것은 원본 모양의 종횡비다.

## 검증

- `trip-navigation-browser-regression.js` 통과: 320/390/844/1280px, 공통 SVG 아이콘 영역·중앙 정렬·글자 크기/굵기/행·4px 간격·선택 배경/밑줄, 직접 진입·Back/Forward·빠른 연속 이동·리포트/PDF·일정 입력 보존·여행 탭·지출/영수증/정산을 확인했다. [실행 기록](verification.json).
- 독립 캡처 검사에서 320/390/760/850/1440px과 DPR 1/1.5, 모바일 편집창, SVG 5개 실제 HTTP 로드를 확인했다. Console의 uncaught page error는 없다. 상대 URL이 외부 CSS 기준으로 해석되는 문제를 캡처 검사에서 발견해 루트 자산 URL로 수정한 뒤 모든 아이콘 로드를 재확인했다.
- `dev test --suite source --json`, `dev build --json`, `git diff --check`, 산출물 구조 검사 통과. 빌드 지문은 `185a67250d70a04e0c8f`다. SVG 5개가 dist와 서비스 워커 자산 목록에 모두 포함됐다.
- 보존 캡처와 원본은 SHA256으로 대조했다. [보존 기록](capture-provenance.json).

독립 Edge/Playwright의 예시 데이터로 검증했으며 사용자 브라우저 저장소·운영 여행·서버 데이터는 변경하지 않았다. 기존 인앱 브라우저 핸들의 `browser.user is unavailable` 문제로 프로젝트가 허용하는 fixture 브라우저를 사용했다. 로컬 소스와 빌드에 반영했고 운영 배포는 하지 않았다.
