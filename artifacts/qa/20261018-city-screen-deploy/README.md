# 도시 삽화·확인창 통합 검증 — 2026-10-18

최신 CLI·터미널 배포본 위에 남아 있던 국내·해외 삽화와 확인창·일정 첨부 UI 변경을 합쳐 검증했다. 실제 사용자 여행은 사용하지 않았으며 Browser plugin not available 상태에서 저장소의 Playwright/Edge 격리 검증을 사용했다.

- 국내 95곳·해외 540곳, 공통 테마 포함 1,290개 활성 이미지. 추가된 WebP 640개와 정확한 생성 원본·보존본·최종 프롬프트의 해시 확인.
- 전체 635곳 × 320/390/599/1440px = 2,540개 헤더, 대표 8곳 × 9너비 = 72개 추가 검사 통과. 제목·그림 겹침과 가로 넘침이 없으며 실제 채색 픽셀의 하단·오른쪽 여백은 2px 미만.
- 확인창 16종 × 6너비 = 96개 검사와 13개 동작 그룹 통과. 취소 기본 포커스, Escape·바깥 클릭·포커스 복귀, 200% 글자, 저장 실패 후 재시도, 첨부·이동 구간의 저장 전 제거를 확인.
- 새 국내·해외 그림의 필요 시 로딩, 미캐시 대체 그림, 오프라인 재표시, 48개 캐시 제한을 확인.
- 실제 iPhone·Android 기기 대신 데스크톱 Chromium 기반 브라우저의 화면 크기별 렌더링을 검증했다.

대표 실제 화면과 수치·동작·해시는 [검증 데이터](verification.json)에 기록한다. 생성 원본·전체 프롬프트는 기존 design 폴더를 보존하며, 원본과 QA 자료는 웹 배포 파일에 포함되지 않는다. 이 문서는 로컬 검증 근거이며 운영 반영은 Git 푸시 이후 운영 파일과 빌드 지문을 별도로 대조한다.
