# 여행 리포트 — 공통 요약·탭·차트 구현

2026-11-03. [선택 목업](../../design/20261102-itinerary-report-tone/README.md)을 구현하고, 사용자가 추가 지정한 ‘요약은 탭 위, 탭 위치는 전환 전후 동일’을 우선 적용했다.

## 변경

- `ui.costSummary.renderMetrics()`를 공통 요약 렌더러로 추출. 지출 분석의 여행 경비·1인 평균·기록한 지출과 일정 분석의 계획 일정·체류·이동이 같은 구조·폰트·아이콘 영역·간격을 사용한다.
- 분석 버튼은 한 DOM 영역을 그대로 유지. 두 요약은 같은 CSS 그리드 셀의 자연 높이를 공유한다. 선택되지 않은 요약은 `visibility:hidden`, `aria-hidden`, `inert`로 비표시·접근성 제외 처리하며 큰 금액이나 긴 시간에도 임의의 고정 높이·음수 여백 없이 탭 좌표를 유지한다.
- 지출·일정이 같은 도넛 패널·범례·캔버스 렌더러·패널 스타일을 사용한다. 일정의 총 입력 시간은 모바일 도넛 중앙에도 표시한다. 금액 분석의 기존 모바일 총액 생략 정책은 유지한다.
- 일정은 시간 비중 도넛, 날짜별 체류/이동 세로 누적 막대, 장소별 아이콘·비례 막대·시간 목록으로 구성. PC는 도넛/날짜 그래프를 나란히, 모바일은 세로로 배치한다.
- 체류는 파랑, 이동은 분홍을 동일 상수에서 범례·도넛·막대에 적용. 미입력 시간을 임의의 숫자로 더하지 않음.
- 날짜 필터·일정순/긴 순/짧은 순·미입력 목록·기존 일정/이동 편집 후 날짜·정렬·스크롤 복귀 유지.
- 기존 공통 여행 컨텍스트·소분류 컬러 아이콘·커스텀 선택창·리포트 PDF 버튼 재사용. 운영 여행 데이터와 서버는 수정하지 않음.
