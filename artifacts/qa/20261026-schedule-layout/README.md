# 지출 가로 정렬·숙소 시작/종료·현재 여행일

2026-10-26 사용자 요청에 따른 로컬 구현·검증 기록이다. 이 변경은 아직 커밋·푸시·운영 배포하지 않았다.

- 모바일 개요 지출 구성은 2열 목록에서 분류명과 비율을 같은 줄에 표시한다. 분류명은 한 줄을 유지하고 비율은 오른쪽에 둔다. 6개 분류와 `1% 미만`, 320/390px 확대 글자까지 검증했다. 목록은 기존 44px 터치 행을 유지한다.
- 모바일 지출 이동 손잡이는 금액 오른쪽에 독립된 44px 열을 사용한다. 320/390px, 긴 설명·큰 원화 금액·외화 보조 금액에서 겹침·넘침 없이 보이고 기존 드래그·키보드 이동·실패 복구가 유지된다.
- 숙소도 기존 시작/종료 시간 컴포넌트 2개를 사용한다. 저장·새로고침·예약 재저장에서 종료 시간을 보존하며 일정 타임라인·요약·점검·캘린더·포켓노트·PDF에 반영한다. 다음 이동 구간의 출발 시각은 숙소 종료 시간을 사용하고, 종료가 비어 있으면 기존처럼 시작 시각을 사용한다. 종료가 시작보다 이른 숙소는 다음 날 종료로 해석한다. 체류 시간 리포트의 숙소 제외 규칙은 기존 의미를 유지한다.
- 개요와 메뉴에서 일정표를 열 때 공통 기본 날짜를 사용한다. 여행 시작 전은 첫날, 기간 중은 여행지의 오늘, 종료 후는 마지막 날이다. 오늘에 항목이 없어도 다른 날짜로 대체하지 않는다. 날짜 버튼을 직접 누르거나 특정 항목·전체 일정 링크를 여는 경우 해당 선택을 유지하고, 메뉴에서 일정표를 다시 열면 기본 날짜로 돌아온다.

모바일 지출 구성은 3열 세로 배치에서 2열 가로 배치로 바뀌어 한 줄의 높이가 추가된다. 기존 카드 높이 검사에는 해당 44px 행만 허용했고, 분류명과 비율의 같은 줄·오른쪽 배치를 직접 검사했다. 이동 검사 fixture는 숙소 종료 후 출발하는 새 의미에 맞춰 목적지 시각을 조정했고, 실제 저장 충돌 차단 검사는 유지했다. 메뉴 애니메이션의 종료 검사는 마지막 샘플의 부동소수점 값 대신 실제 종료 상태를 기다려 완전한 불투명도를 확인한다.

대표 캡처·원본 경로·SHA256·빌드 지문은 `verification.json`에 있다. 전체 임시 출력은 `artifacts/tmp/20261026-schedule-layout/`에 있다.
