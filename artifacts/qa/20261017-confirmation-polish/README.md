## 검증 환경과 범위

Browser 플러그인과 `browser` 스킬이 제공되지 않아 기존 Playwright 환경을 사용했습니다. Edge 및 Chromium headless shell에서 외부 요청을 차단한 별도 계정·여행·저장소로 검증했습니다. 실제 iOS·Android 기기 검증은 수행하지 않았고, 공유 서버 작업은 가상 명령 응답으로 확인했습니다.

작업 도중 별도의 국내 도시 확장 변경이 공유 작업 폴더에 추가됐고, 당시 도시 데이터가 아직 없는 이미지 160개를 참조하여 전체 소스 검사가 실패했습니다. 그 변경은 수정하지 않았습니다. 기준 커밋 `b146d47b72cb3ee617cec7d310a7b0741db74deb`에 이번 UI 소스 8개 파일의 변경만 적용한 작업 폴더에서 최종 기본 테스트·확인창·스크롤·시각 검증과 빌드를 완료했습니다. 검증한 8개 파일은 원래 작업 폴더의 UI 소스와 일치하며 줄바꿈과 생성된 빌드 지문만 정규화해 비교했습니다.

| 실행 | 결과 |
| --- | --- |
| `npm test` | 분리 환경에서 통과 |
| `node scripts/delete-dialogs-browser-regression.js` | 분리 환경에서 96개 화면·13개 동작 그룹 통과 |
| `node scripts/scroll-lock-browser-regression.js` | 분리 환경에서 320/390/1440px 스크롤·취소·저장·포커스 통과 |

| 추가 시각 검사 | Chromium 12개 화면, 대비, 200% 글자, 짧은 화면, 긴 파일명과 파일 교체·제거 통과 |
| `npm run build` | 분리 환경에서 통과. 빌드 파일 912개와 배포 출력의 바이트 일치 확인 |
| 산출물 | 디자인·검증 자료는 `artifacts/`에 보관하며 배포·서비스 워커 캐시에서 제외 |

분리 빌드 지문은 `1b2d90c16b5b947efda2`이며 HTML과 서비스 워커가 일치합니다. 이 기록은 **이번 UI 수정의 로컬 검증**입니다. 공유 폴더의 모든 동시 작업이 통합 검증됐거나 운영 배포됐다는 의미가 아닙니다.

## 목업 대조

| 비교점 | 목업과 구현 |
| --- | --- |
| 배경·색 | 흰 표면과 앱의 남색·연분홍·노랑·하늘색을 적용 |
| 구성 | 왼쪽 동작 아이콘, 오른쪽 질문·대상·설명, 아래 동일 폭 버튼 |
| 크기·여백 | 최대 342px, 20px 패딩, 16px 모서리와 얇은 윤곽선 |

| 아이콘 | 기존 Phosphor regular의 휴지통·보관·초기화·사람 제거·나가기 |
| 입력 중 제거 | 하늘색 파일 선택, 연분홍 제거, 저장 시 반영 안내를 유지 |
| 긴 파일명 | 좁은 열에 글자가 쌓이던 초기 구현을 수정하여 이름과 버튼을 별도 행으로 배치 |
| 문구 | 기존 16개 상태의 정확한 질문·대상·영향·동작 이름 검증 통과. 추가된 사용자 노출 문구 없음 |

의도적인 차이는 세 가지입니다. 생성 이미지가 임의로 추가한 중복 설명은 생략했습니다. 두 번째 목업의 기기 프레임·임의 로고·내비게이션·바텀시트 대신 실제 앱의 편집기를 사용했습니다. 키보드 포커스 테두리와 긴 파일명 반응형은 실제 조작을 위해 적용했습니다. 이 범위를 제외한 컴포넌트 구성·색·크기·서체·아이콘을 실제 캡처와 목업으로 대조했으며 남은 시각적 수정 사항은 없습니다.
