# 일정 요약 편집 아이콘 위치 조정

- 하단 전체 너비 `일정 다듬기` 버튼 제거. 시각·장소 수·미입력 배지 정보 줄의 오른쪽 끝에 18px 연필 아이콘을 배치했다.
- 별도 배경·테두리 없는 32px 버튼. 접근성 이름과 툴팁으로 날짜별 일정 편집 동작을 알린다. 상세 목록을 접어 둔 상태에서도 사용 가능하다.
- 좁은 화면에서 정보가 줄바꿈돼도 오른쪽 아이콘 공간을 유지하고 마지막 정보 줄과 정렬한다.
- 기존 요약 브라우저 회귀 및 CLI 소스 검사, 빌드 통과. 320/390/1440px 실제 카드 캡처 확인.
- 운영 여행 데이터·커밋·푸시·배포 변경 없음. 현재 로컬 수정 상태.
