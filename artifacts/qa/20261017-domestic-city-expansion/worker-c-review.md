# Worker C — 국내 목적지 삽화 19쌍 검수

검수일: 2026-10-17. 담당 범위는 `generation-assignments.json`의 `worker-c` 19개 목적지, PC·모바일 각 1장으로 총 38장이다. 각 이미지에 한 번의 독립 T2I 호출을 사용했고, 시각 검수 후 5장을 독립 T2I로 교정했다. 입력 이미지를 첨부한 호출은 없다.

## 최종 결과

- 38장 모두 원본 PNG, 호출 provenance JSON, WebP 변환 메타데이터 JSON, 실행용 WebP가 존재한다.
- PC 19장: 800×480. 모바일 19장: 480×600. 모든 WebP에서 알파 최솟값 0, 최댓값 255를 확인했다.
- 원본 PNG는 각 호출이 반환한 정확한 경로의 파일과 SHA256이 같다. 38개 최종 반환 원본 경로는 모두 고유하다.
- 작업 JSON·실제 호출 문구·provenance·프롬프트 파일·프롬프트 SHA256이 모두 일치한다. `imageInputs`는 모두 빈 배열이다.
- 최종 WebP 38장 합계: **3,685,252 bytes**. 검증 상세는 [worker-c-technical-validation.json](worker-c-technical-validation.json)에 보존했다.
- 실행 자산은 `src/assets/trip-scenes/cities/v5/`에 저장했다. 앱 코드·카탈로그·빌드·Git 커밋에는 이 작업자가 관여하지 않았다.

실행용 최종 WebP를 옅은 배경에 합성한 4개 contact sheet를 직접 열어 확인했다. 작업용 전체 시트는 `artifacts/tmp/20261017-domestic-city-expansion/worker-c-contact-1.png`부터 `worker-c-contact-4.png`까지다. [대표 시트 1](worker-c-contact-1.png)과 [대표 시트 3](worker-c-contact-3.png)을 이 폴더에 보존했다.

신규 묶음은 짙은 남색 외곽선·녹색 식생·모래색 길·청록 수면이 일관된다. 기존 `v2/kr-suncheon.webp`와 직접 비교했을 때 신규 그림은 건축·수목 묘사가 더 촘촘하다. 기존 순천과 세부 묘사 밀도까지 완전히 같다고 판정하지 않았다.

이 검수는 자산 자체의 모아보기다. 실제 헤더의 320·390px, 전환점 양쪽, 중간 패널·PC·긴 여행명 합성 검증은 주 작업자가 수행한다. 특히 하단·왼쪽의 가는 밝은 가장자리와 오른쪽 테두리 연결은 실제 헤더에서 추가 확인한다.

## 교정과 원본 보존

교정한 5장: 세종 PC·모바일, 서산 PC, 영주 PC·모바일. 첫 결과와 프롬프트·작업 JSON·provenance·WebP 메타데이터·WebP를 `artifacts/design/20261017-domestic-city-expansion/revisions/worker-c-r1/`에 보존했고, [supersession.json](../../design/20261017-domestic-city-expansion/revisions/worker-c-r1/supersession.json)에 이전 경로·보존 경로·SHA256·교정 사유를 기록했다. 도구가 반환한 원본 파일은 원래 경로에도 유지했다.
