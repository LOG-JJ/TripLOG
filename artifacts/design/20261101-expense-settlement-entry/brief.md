# 지출 상단 경비 정산 진입 — 배치 목업

2026-11-01 · Asia/Seoul

사용자 요청은 하단 지출의 펼침 동작을 제거하고 경비 정산 버튼을 영수증 왼쪽에 배치하는 것이다. 해당 배치 목업이 없어 확인을 요청했으며, 사용자는 ‘배치 목업 먼저 확인’을 선택했다. 앱 구현 전에 이미지 목업만 제작했다.

- 모바일: 지출 기록 제목 오른쪽에 경비 정산 / 영수증을 나란히 배치한다.
- PC: 경비 정산 / 영수증 / 지출 추가 순서다.
- 경비 정산은 영수증의 기존 하늘색 보조 버튼 규격과 아이콘을 재사용하는 방향이다.
- 하단 지출은 일정처럼 지출 기록으로 직접 진입하고 펼침 표시를 제거하는 방향이다. 리포트 펼침 메뉴는 기존 기능을 따른다.
- 검토 범위는 상단 진입 버튼 배치와 하단 지출 직접 진입이다. 본문·여행 삽화·표의 세부 표현을 새로 개편하는 승인으로 확대하지 않는다. 320px에서는 실제 구현 단계에 버튼 문구 줄바꿈·제목 겹침을 확인한다.

[목업 이미지](expense-settlement-placement.png), [최종 프롬프트](prompt.txt), [생성 기록](generation.json).

이미지 입력 없는 T2I 1회로 생성했다. 이미지 생성 도구가 반환한 정확한 원본 경로를 기준으로 저장했고 원본·보존본 SHA256이 일치한다. 기존 파일은 덮어쓰지 않았다. 앱 소스·사용자 데이터·배포에는 변경하지 않았다.

후속: 사용자가 이 목업에 ‘ㄱㄱ 구현해줘’로 구현을 요청했다. 해당 배치와 지출 직접 진입을 적용한 결과는 [구현 QA](../../qa/20261101-expense-settlement-entry/design-qa.md)에 보존한다. 생성 원본과 프롬프트는 유지한다.
