# 일정 요약 아이콘 중심 목업

- 날짜: 2026-10-28
- 방식: built-in image_gen, T2I. 이미지 입력 없음.
- 목표: 접힌 일정 요약에서 로그형 설명·미입력 안내·긴 화살표 문장을 제거하고 컬러 아이콘, 숫자, 짧은 장소명으로 표현.
- 화면 기준: 모바일 390 × 844 CSS px.
- 표시 순서: 1 calendar-badge.png, 2 color-journey.png, 3 five-day-index.png.
- 각각 독립 생성한 원본이며 실제 앱 코드·여행 데이터·배포는 변경하지 않음.
- 선택 대기. 최종 프롬프트, 정확한 생성 원본 경로와 SHA256은 generation.json 참조.
