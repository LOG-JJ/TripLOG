## 디자인 비교

| 항목 | 기준과 확인 |
| --- | --- |
| 프레임 | 다섯 카드가 같은 `overview.card.render`를 사용하며 배경·테두리 색/굵기·모서리·그림자·본문 글꼴의 실제 computed style이 모두 같다. |
| 제목 행 | 예약·경비·일정의 제목 글꼴/크기/굵기/색/행간이 같다. 제목 아이콘과 이동 버튼은 한 공통 helper/CSS에서 관리한다. |
| 내용·높이 | 경비의 긴 금액 목록을 얇은 구성 막대와 2줄 비율 표시로 압축했다. 대표 일정은 시간순 5개, 6번째 이후는 전체 보기에 남는다. |
| 색과 의미 | 개요의 네이비 윤곽선·흰 표면·회색 보조문구를 사용한다. 파스텔 색은 실제 지출 구성의 세그먼트와 해당 항목의 점에만 사용한다. |
| 값·문구 | 합계·건수·1인 평균은 실제 기록에서 계산한다. 비율은 읽을 수 있는 문자로도 표시하고 세그먼트 길이는 금액 비율과 일치한다. |
| 여백·반응형 | 320/390/599/759/760/849/850/1024/1440px 넘침 검사 통과. PC의 경비/일정 카드 높이가 같고, 모바일에서는 두 카드가 차례로 배치된다. |
| 상호작용 | 항목을 클릭하거나 Enter로 실행하면 기존 검색/시기 조건을 초기화하고 해당 지출 목록으로 이동한다. 키보드 포커스도 제목으로 이동하며 여행 데이터는 바뀌지 않는다. |

생성 목업과 실제 화면을 직접 열어 비교했다. 최종 공통 프레임은 사용자가 지정한 기존 개요 스타일을 기준으로 적용했다. 목업의 임의 브랜드/메뉴·과도한 높이는 복제하지 않았다. 위 기준에 대한 미해결 시각 문제는 없다.
