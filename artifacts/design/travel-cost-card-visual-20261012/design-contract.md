# 개요 공통 카드 · 컴팩트 여행 경비 · 대표 일정 5개

## 최종 사용자 요구

개요의 여행 정보·예약 요약·여행 경비·첫날 일정·준비물은 같은 카드 컴포넌트를 사용한다. 차이는 내용과 크기 규격에 한정한다. 여행 경비는 기존 확장형의 절반 수준으로 줄이고 대표 일정은 최대 5개를 표시한다.

## 공통 구조

- `src/app/features/overview/overview-card.js`가 모든 카드의 프레임과 공통 제목 행을 생성한다.
- `render`는 content, hero, reservations, action의 네 가지 레이아웃 규격을 받는다. 카드 외관은 모든 규격에서 같다.
- `header`는 제목, 아이콘, 배지, 날짜 등의 보조 정보, 이동 버튼을 받는다. 예약 요약·여행 경비·대표 일정이 같은 제목 행을 사용한다.
- `src/styles/overview-cards.css`가 흰 바탕, 기존 네이비 테두리(1.5 CSS px), 10px 모서리, 글꼴, 제목/아이콘/버튼, 공통 여백을 관리한다.
- 각 기능의 CSS는 본문 배치와 크기만 관리한다. 경비 카드의 별도 파란 테두리·네이비/파란 보조색·헤더 스타일은 제거했다. 기존 여행 헤더와 예약 카드의 중복 프레임 선언도 제거했다.

## 내용 및 크기

- 경비: 누적 합계 → 한 줄의 지출 건수·1인 평균 → 10px 지출 구성 막대 → 3열, 최대 2줄의 짧은 항목/비율 목록.
- 항목을 실행하면 해당 분류의 지출 목록으로 이동한다. 이전 검색과 시기 필터는 초기화하고 키보드 포커스를 지출 화면 제목으로 옮긴다. 항목별 정확한 금액은 이동한 목록, 접근성 이름, 제목 도움말에서 확인한다.
- 합계는 기존 누적 경비 계산을 사용한다. 구성은 양수 지출 기준이며 환불이 있는 경우 계산 기준을 주석으로 표시한다.
- 대표 일정은 기존 시간순 목록에서 최대 5개를 표시한다. 임의 일정은 실제 여행에 추가하지 않는다. 6개 이상은 기존 전체 보기로 확인한다.
- 일반 예시에서 경비 카드 높이는 약 574px에서 약 266px로 줄었다. PC에서는 동일한 그리드 행으로 대표 일정 카드와 높이를 맞춘다. 내용이 긴 경우 가독성을 위해 높이가 늘어날 수 있다.
- 모바일 320/390px, 849/850px 전환점 양쪽, 1440px PC를 포함해 검증한다.

## 목업 기록과 적용 범위

T2I로 생성한 `../20261012/triplog-travel-cost-visual-card-20261012.png` 및 `../20261012/triplog-travel-cost-compact-20261012.png`와 각 `.prompt.json`을 보존했다. 둘 다 이미지 입력 없이 한 번씩 생성했고 정확한 반환 원본과 저장 PNG의 SHA256이 일치한다. 원본과 프롬프트를 덮어쓰지 않았다.

최종 기준은 사용자가 지정한 기존 개요의 공통 카드와 절반 높이다. 생성 이미지의 세로 목록, 임의 브랜드/메뉴, 큰 아이콘을 구현 조건으로 추가하지 않는다. 기존 공통 디자인을 재사용하는 구조 정리는 추가 시각 방향 탐색 없이 수행했다. [최종 비교·실제 화면·검증](../design-qa.md)에 결과를 기록했다.
