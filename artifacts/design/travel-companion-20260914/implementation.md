# TripLOG 여행 동행 기능

구현 기준: 2026-09-14 생성한 `today.png`, `review.png`, `wallet.png`, `tools.png`, `adjustment.png`, `reservation-editor.png`. 기존 흰색 바탕, 검정 외곽선, 노랑 주요 버튼, 파랑·분홍 포인트와 Pretendard를 유지한다. 모바일 393×852를 기준으로 구현하고 320px와 PC 중앙 정렬을 검증한다.

## 제공하는 기능

- 오늘의 여행: 여행일 선택, 다음 미완료 장소, 완료 표시, 길찾기, 남은 기간을 고려한 하루 가용 예산.
- 일정 점검: 시간 겹침, 이동 시간 부족, 시간 미입력과 여행 기간 밖 일정을 표시한다. 지연 시간을 반영한 조정은 미리보기 후 적용하고 한 번 되돌릴 수 있다. 완료·잠금 일정은 이동하지 않는다.
- 예약 지갑: 기존 항공·숙소 사전구매와 일정 바우처를 모으고, 수동 예약의 추가·수정·삭제, 예약번호 복사, 상세 정보, 일정 연결을 제공한다.
- 여행 도구: 선택한 여행지 시간대를 적용한 ICS 파일과 네트워크 없이 읽을 수 있는 독립 HTML 포켓노트를 내려받는다. 예약번호·예산 포함 여부를 선택할 수 있다.

모두 브라우저에서 계산·저장하며 유료 API를 추가하지 않는다. 길찾기는 외부 지도 링크다. 포켓노트는 내려받은 정적 문서이며 웹앱 전체의 오프라인 동기화를 뜻하지 않는다.

## 데이터와 검증

`travelCompanion`에 완료·잠금 일정 ID, 수동 예약, 시간대와 마지막 시간 조정 기록을 보관한다. 여행 생성·전환·백업·복원·초기화에 반영한다. 일정 공유를 끈 경우 예약 지갑과 진행 상태도 공유하지 않는다. 기존 Supabase JSON 저장 구조와 인증·RLS는 변경하지 않는다.

시간 조정은 날짜, 일정 내용과 잠금 상태가 미리보기 이후 달라지면 적용하지 않는다. 자정 초과, 누락된 시간 또는 잠긴 일정과 충돌하면 적용을 막는다. 되돌리기도 이후 일정 편집을 덮어쓰지 않는다.

ICS는 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545)에 따라 CRLF, UTF-8 75바이트 줄 접기, 텍스트 이스케이프, 안정적인 UID, 종일 일정의 배타적 종료일을 사용한다. 시간대의 DST 중복·존재하지 않는 시각은 조용히 추정하지 않고 표시한다.

iPhone의 캘린더 자동 등록을 약속하지 않는다. [Apple의 iPhone 안내](https://support.apple.com/guide/iphone/ipha0d932e96/ios)에 따른 Mail 첨부파일 가져오기 안내를 다운로드 후 표시한다. 실제 iPhone의 파일 열기·캘린더 앱 동작은 실기기 검증 범위에 포함되지 않는다.

## 목업 문구 보정

- 오늘 화면의 부제는 ‘다음 여행’ 대신 실제 동작에 맞는 ‘다음 장소’로 표기한다.
- 가용 예산 96,000 / 150,000원 예시의 하단은 계산과 일치하도록 ‘오늘 사용 54,000원’으로 표기한다.
- 잠금은 상태와 동작을 구분하여 ‘잠금’ / ‘잠금 해제’, 완료는 ‘완료 취소’로 접근성 이름을 제공한다.

## 기존 입력 문제

국가 입력은 네이티브 텍스트 필드와 한·영 검색으로 정리했다. Chrome에서 조합 중 삭제 후 완성된 글자까지 지워지는 것을 확인했다. Codex 내장 브라우저에서는 사용자의 실제 입력 기록상 조합 종료 뒤 삭제 이벤트가 페이지에 도달하지 않아 완성된 글자가 남는다. 이 호스트 문제는 웹앱 수정으로 해결했다고 주장하지 않는다. 새 기능의 입력 검증도 Chrome에서 진행한다.
