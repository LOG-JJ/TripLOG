`place-edit-actions-mockup.png`는 하나의 제안 흐름을 기본 화면, 이름 변경, 주소 변경의 세 상태로 보여줍니다. 각 상태의 목표 화면은 390 × 844 CSS px입니다. 이름·주소 변경 버튼을 장소 요약 아래에 나란히 두고, 이름은 작은 편집창에서, 주소는 검색과 지도에서 변경하도록 제안합니다.
