# 일정 계획 사용성 기능 목업

2026-10-26. 사용자 검토용 목업이며 앱 구현·배포는 진행하지 않았습니다.

390 × 844 CSS px 모바일 화면을 목표로 네 상태를 한 장에 배치합니다.

- 왼쪽 위: 앞뒤 일정 요약과 시간 겹침 안내
- 오른쪽 위: 체류시간으로 종료시간 빠르게 설정
- 왼쪽 아래: 이번 여행에서 사용한 장소 재사용
- 오른쪽 아래: 저장 후 다음 일정 연속 추가

지도 아래 세 버튼, 최상단 Day·날짜 정보, 이름·주소 변경, 메모 중심 입력이라는 기존 제안 맥락을 유지합니다. 모든 기능은 아직 제안 단계입니다. 이미지 속 지도·장소·시간·주소는 예시입니다.

기존 이미지 입력 없이 T2I 한 회로 생성했습니다. `itinerary-usability-board.png`를 도구가 반환한 정확한 원본에서 복사하고 SHA256을 대조했습니다. 최종 프롬프트는 `prompt.txt`, 원본 경로·생성 시각·해시는 `generation.json`에 보관합니다. 사용자 선택은 미정입니다.
