- 긴 안내 문장과 반복되는 구간 1 표기를 줄이고 출발·도착 아이콘, 점선, 미정 시간과 시간 입력 동작을 정렬한 구간 목록.

- 구현 검증: `artifacts/qa/20261028-summary-detail-transit/`. 운영 여행 데이터와 배포 변경 없음.

- 원본 및 입력 이미지 SHA256과 최종 프롬프트는 generation.json 참조.
