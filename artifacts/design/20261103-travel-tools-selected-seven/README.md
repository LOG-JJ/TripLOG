## 디자인·구현 연결 기준

- 흰 바탕, 남색 글자·테두리, 노란 주요 동작·선택 상태, 연한 파란 보조 컨트롤, 제한적인 분홍 포인트, 작은 오프셋 그림자.
- 글자 크기·두께를 절제하고 도구별 독립 접근을 유지. 사진·거대한 히어로·긴 설명문은 사용하지 않음.
- 공통 헤더·여행 컨텍스트·탭·버튼·입력·체크 목록·날짜·시간·드롭다운·대화상자 패턴 재사용.
- 실제 구현 시 `src/app/ui/markup.js`, `trip-context.js`, `custom-select.js`, `date-picker.js`, `time-picker.js`, `dialog.js` 및 기존 준비물 컴포넌트를 우선 사용.
- 하단 내비게이션: 개요 / 일정 / 여행 / 지출 / 리포트. 여행 활성 상태, 5개 아이콘·라벨 크기와 정렬 통일.
- 여행 탭: 오늘의 여행 / 예약 지갑 / 여행 도구. 여행 도구 활성 상태.
- 이 이미지는 새 상세 화면의 사용자 검토 자료이며, 상세 화면 전체의 구현 승인을 의미하지 않음.

## 예시 데이터

- 모든 여행명·일정·SSID·시간·일출·일몰·카운트다운·준비물은 목업용 예시. 운영 여행 데이터에서 읽거나 수정하지 않음.
- 서울 2026-11-03 09:00 ↔ 뉴욕 2026-11-02 19:00의 날짜·요일·시차는 Node `Intl.DateTimeFormat`으로 확인.
- 일출 06:06·일몰 16:44는 레이아웃을 위한 예시이며 해당 도시·날짜의 천문 계산 검증값이 아님.
- QR은 이미지 목업 속 표시 예시. 실제 연결 가능한 QR은 구현 단계에서 입력값으로 생성해야 함.
- 단위 예시: 68°F = 20°C, 10mi ≈ 16.09km, 10lb ≈ 4.54kg.
