## 구현 시 유지할 조건

- 상단 필요한 예약에는 여행지 현지 이용일이 당일인 교통·입장권·식당 등의 예약만 표시한다. 숙소는 숙박 중이거나 당일 체크인해도 상단에서 제외하고 전체 목록·숙소 필터에서 접근한다.
- 당일 예약이 없으면 안내 한 줄과 전체 예약 접근만 제공한다. 다른 날짜 예약이나 숙소로 대체하지 않는다. 넓은 빈 상태 영역을 요구하지 않는다.
- 예약 목록에서는 시각·이름·예약번호 복사·원본 열기 등 필요한 정보만 표시하고 주소·인원·좌석·메모는 상세에서 확인한다.
- 원본 티켓 링크와 예약 관리 링크를 구분한다. 원본 티켓 링크가 없으면 예약정보 보기로 연결한다.
- 숙소는 체크인·체크아웃 날짜와 선택 시각, 교통은 출발·도착 날짜·시각, 입장권은 이용 날짜·시각을 입력한다. 숙소 일정 자동 생성과 기존 날짜별 시각 보존 조건은 유지한다.
- 금액·지출 연동 및 추가 메모는 기본 접힘 상태다. 금액 연동의 상세 계약은 ../20261028-wallet-expense-link/behavior-proposal.md와 최신 지출 연동 목업을 함께 참조한다. 예약 총액과 실제 결제 기록은 구분한다.
- 기존 지출을 선택하면 해당 지출을 재사용한다. 기존 일정을 선택하면 새 일정을 중복 생성하지 않고 연결하며, 새 일정 추가는 별도 선택으로 둔다.
- 연결된 일정·지출은 작은 행과 보기 동작으로 제공한다. 배경 화면은 톤 참조일 뿐 상단 예약 선별 규칙을 바꾸지 않는다.
- 모든 종류는 공통 상세 창과 폼을 재사용하고 종류에 따른 필드·주요 버튼만 바꾼다. 실제 구현에서는 기존 소분류 컬러 아이콘을 재사용한다.

## 확인 범위

목록 → 상세 → 추가/편집 → 지출·일정 연결 및 네 가지 보조 상태의 주요 시각 기준을 마련했다. 현재 산출물은 동작하는 프로토타입이나 브라우저 검증 결과가 아니며, 구현 후 실제 모바일·PC 반응형 및 저장·취소·연결 검증이 필요하다.

원본 이미지 경로, 최종 프롬프트, 입력 이미지 역할, 생성 방식, SHA256은 generation.json에 보존한다.
