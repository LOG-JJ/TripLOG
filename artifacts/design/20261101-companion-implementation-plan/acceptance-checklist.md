# 통합 개편 인수 기준

작성일: 2026-11-01. 아래 항목은 원래의 **검증 계획**을 보존한다. 실제 실행한 자동 검사·브라우저 비교·남은 실기기 제약은 [구현 QA](../../qa/20261101-companion-redesign/design-qa.md)에 따로 기록한다. 아래 체크박스를 일괄 통과 결과로 바꾸지 않는다.

## 날짜·진행

- [ ] 여행 전 첫날/기간 중 현지 오늘/종료 후 마지막 날, 직접 선택한 날짜 보존.
- [ ] 현지 자정·화면 복귀·잘못된 시간대·긴 기간에서 날짜/Day/예약 선별 일치.
- [ ] 완료/건너뛰기/여기부터 시작이 시간·순서를 바꾸지 않음.
- [ ] 건너뛰기는 완료 수를 증가시키지 않음. 시작 이동은 앞선 일정을 자동 처리하지 않음.
- [ ] 다음 선택이 무조건 첫 미완료로 돌아가지 않음. 같은 장소명은 ID로 구분.
- [ ] 되돌리기가 다른 사용자의 이후 변경을 덮어쓰지 않음.
- [ ] 삭제·재정렬·다른 날짜 이동·계정/여행 전환 후 개인 진행 참조 정리.
- [ ] 보기 전용 사용자는 공유 완료를 변경하지 못하며 개인 화면 선택은 가능.

## 오늘의 여행·빠른 지출

- [ ] 대표 장소 변경 시 예약/번호/숙소/다중 이동이 함께 변경.
- [ ] 예약/숙소 없을 때 관련 버튼 제거 후 남은 버튼 배치 정상.
- [ ] 숙소가 겹치면 선택 제공, 체크아웃 날 숙소로 잘못 연결하지 않음.
- [ ] 첫 장소에 고립된 incoming leg를 표시하지 않음. 다중 leg 누락 없이 표시.
- [ ] 빈 일정/모두 완료/건너뛴 항목만 남음/여행 전후 상태 표시.
- [ ] 빠른 지출 초깃값은 수정 가능, 결제일과 이용/여행 일자 구분.
- [ ] 외화 원금과 환율 기준 단위로 기존 원화 합계와 동일하게 계산.
- [ ] 키보드 열린 상태에서 금액·오류·저장에 접근 가능, 하단 탐색/안전 영역과 겹치지 않음.
- [ ] 저장 실패 시 입력 유지, 성공 전 합계/건수 확정 없음, 중복 탭/재시도 한 건.

## 예약 목록·상세·원본

- [ ] 오늘 상단에는 당일 숙소 외 예약만 표시, 미래/지난/숙소 대체 없음.
- [ ] 숙박 중/당일 체크인 숙소는 상단 제외, 전체/숙소 목록에는 유지.
- [ ] 왕복의 귀국편이 해당 이용일에 노출되고 원본 예약/지출 중복 없음.
- [ ] 진행 중 숙소·왕복 예약은 최초 날짜만으로 지난 예약이 되지 않음.
- [ ] 검색/종류 필터/정렬/지난 예약 접힘/상세 복귀 문맥 유지.
- [ ] 티켓/관리 링크 구분, 없는 링크의 버튼 문구/동작 일치.
- [ ] manual/entry/plan 출처별 편집이 원본으로 연결되고 수동 복제하지 않음.
- [ ] 기존 첨부 접근 보존, 신규 파일 첨부가 주요 흐름에 생기지 않음.
- [ ] 기존 일정 연결 시 중복 생성 없음. 숙박일 자동 일정과 날짜별 직접 수정 보존.
- [ ] 종류 전환/취소/재열기/외부 동시 수정에 입력·필드·연결 상태 정확.

## 예약↔지출·저장·공유

- [ ] 금액만 기록/연동 끔은 지출을 생성하지 않음.
- [ ] 새 결제 생성은 한 건, 기존 지출 선택은 동일 ID 재사용.
- [ ] 명시 연결된 사전구매 예약이 지갑에서 중복 표시되지 않음.
- [ ] 예약 이용일/제목/총액만 수정하면 실제 지출 금액·결제일 유지.
- [ ] 실제 결제 수정은 동일 지출 ID 갱신, 결제자/분담 연결 보존.
- [ ] 일정 자동 교통비에 연결된 지출의 소유 규칙을 무단 변경하지 않음.
- [ ] 연결 해제/예약 삭제/취소 시 기존 지출 유지. 실제 환불과 별도.
- [ ] 연결 지출 삭제/권한 상실 후 없는 금액을 캐시로 표시하지 않음.
- [ ] 저장 실패·동기화 충돌·오프라인 재시도에서 한쪽만 저장되거나 중복되지 않음.
- [ ] 지출 비공개/일정 공유 조합에서 예약을 통한 금액/결제자 우회 공개 없음.
- [ ] 새 필드가 정규화·CLI·file/cloud·JSON 백업·복원·동기화 왕복에서 보존.
- [ ] 서버 확인 전 기기 저장 성공과 서버 반영 완료를 구분.

## 도구·분석

- [ ] 준비물 요약과 전체 편집의 체크/추가/이름 수정/순서/삭제/초기화 일치.
- [ ] 전체/남은 필터와 빈/모두 완료/중복 이름/저장 실패 상태 정확.
- [ ] HTML 선택 범위·미리보기·실제 파일 내용 일치. 포함 해제한 예약/금액 노출 없음.
- [ ] 기존 references/CLI 출력 호환 유지, 기록된 경비만 포함.
- [ ] ICS 시간대·날짜 넘김·특수문자·빈 일정 오류 처리, 계정 동기화로 표현하지 않음.
- [ ] 분석의 전체/날짜 합계가 같은 정의로 계산되고 null과 0 구별.
- [ ] 숙소/교통 테마/겹친 시간/자정 넘김/다중 leg/기간 외 항목의 의미 일관.
- [ ] 날짜 비교는 공통 0점·선형 축, 직접 값/단위, 짧은 막대 라벨 가독성 확보.
- [ ] 정렬 동률 안정성·미입력 마지막, 입력 후 해당 항목/leg/필터/정렬로 복귀.
- [ ] 일정 점검 메뉴·탭·활성 진입 제거, 기존 호출은 정해진 호환 경로로 연결.

## 실제 화면 비교

- [ ] 320/390/768/1440px 및 모바일 전환점 양쪽에서 캡처 비교.
- [ ] 긴 여행명/주소/예약번호와 1개/다수 항목에서 정보 밀도·줄바꿈 비교.
- [ ] 하단 탐색 중복 없음, 뒤로 가기/닫기/포커스 복원/스크롤 보존.
- [ ] 실제 iOS/Android 가능 환경에서 키보드·다운로드·외부 지도 복귀 확인.
- [ ] 색 이외의 상태 표시, 아이콘 버튼 이름, 키보드 조작, 터치 영역 확인.
- [ ] 대표 목업과 동일 데이터로 카드 높이/글꼴/노출 항목 수 비교.

## 완료 기록

실행한 명령·결과·남은 제약만 QA 문서에 기록한다. 모델/CLI/브라우저 테스트를 실제 실행한 것으로 바꿔 적지 않는다. 로컬 완료·Git 푸시·운영 반영 확인을 구분한다.
