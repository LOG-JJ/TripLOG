# TripLOG 확인창 톤 정리 — 2026-10-17

직전 개선한 [18가지 삭제·제거 경로](../20261017-delete-dialogs/README.md)를 현재 앱의 색과 서체에 맞추고, 작은 크기를 유지하면서 조작과 가독성을 다듬었습니다.

- [확인창 목업](01-confirmation-system.png): 일반 삭제, 연결 지출 삭제, 공유 여행 보관, 초기화.
- [입력 중 제거 목업](02-inline-removal.png): 예약 증빙 첨부와 이동 구간 옵션.
- [최종 프롬프트](prompts.md), [브리프](brief.json), [원본 경로·SHA256·선택 기록](generation.json).
- [실제 화면과 검증 기록](../../qa/20261017-confirmation-polish/README.md).

두 이미지 모두 입력 이미지 없는 T2I로 생성했습니다. 반환된 정확한 원본을 새 경로에 복사하고 SHA256 일치를 확인했으며 기존 목업은 덮어쓰지 않았습니다.

| 요소 | 구현 기준 |
| --- | --- |
| 색상 | 흰 배경, 남색 잉크 `#0b1020`, 연분홍 `#f7afc7`, 노랑 `#fff05a`, 파일 선택 하늘색 `#bce6fb` |
| 확인창 | 최대 342px, 좌우 최소 16px, 패딩 20px, 모서리 16px, 얇은 윤곽선과 작은 그림자 |
| 글자 | 기존 Pretendard, 제목 18px, 대상·설명·버튼 14px, 도움말 12px |
| 아이콘 | 기존 Phosphor regular, 54px 배경 안 32px 동작 아이콘; 보조 그림은 스크린리더에서 제외 |
| 버튼 | 확인창 48px, 입력 중 제거 44px 이상; 취소 기본 포커스, 키보드 포커스 표시 |
| 동작별 표현 | 삭제·제거·초기화는 연분홍, 공유 여행 보관과 일반 확인은 노랑 |
| 움직임 | 160ms 진입 전환, 동작 줄이기 설정에서는 생략 |
| 긴 파일명 | 24자를 넘거나 359px 이하 화면일 때 파일명 한 행과 나란한 두 버튼으로 재배치 |

목업의 기본 구성·색·서체 계층·버튼·아이콘을 구현 기준으로 사용했습니다. 생성 이미지가 일반 일정 삭제에 추가한 “이 일정이 삭제돼요.”는 중복 설명이어서 넣지 않았습니다. 입력 중 제거 목업의 기기 프레임, 임의 로고·내비게이션·예시 바텀시트는 컴포넌트 주변의 표현이며, 실제 앱의 편집기와 배치를 유지합니다. 키보드 포커스 테두리와 긴 파일명 반응형은 실제 사용을 위한 차이입니다.
