# 오늘의 여행 선택안 조합·상단 조작 개선

2026-11-01 · 수정 이미지 목업 단계 · 앱 구현 전 확인

결과: [선택안 조합 목업](combined-refinement.png). 왼쪽부터 초기 화면, 방문 완료 후 화면, 이날 지출 상세다. 생성 프롬프트·입력 역할·정확한 반환 원본·보존본 SHA256은 [generation.json](generation.json)에 기록했다. 입력 3개 중 두 선택안은 기존 디자인 폴더에서 보존하고, 공통 여행 정보의 실행용 아이콘 원본은 이 폴더에 재생성 참조용으로 별도 복사했다.

## 사용자 선택

- 여행 메인: 이전 세트에서 첫 번째로 표시된 `compact-overview.png`의 메인 구조.
- 지출 상세: 이전 세트에서 세 번째로 표시된 `visual-summary.png`의 지출 상세 구조.
- 선택안의 사진은 기존 프로젝트의 범용 소분류 컬러 이모지/아이콘으로 대체. 장소마다 별도 그림이나 사진을 준비하지 않음.
- 전체 글자 크기·굵기를 낮춤. 제안은 본문 13–14px/400–500, 장소명 17–18px/500–550, 큰 금액 22px/600 이내. 전역 700–900 굵기를 새 화면에 상속시키지 않음.

## 새 요청을 반영할 구성

- 일정 계획의 공통 `ui.tripContext`를 사용. 여행명·기간·숙박 수와 기존 여행 아이콘을 재사용하고 `여행명 + 도시 + 지난 일정 + 완료 문장`의 중복 나열을 제거.
- 공통 여행 정보 오른쪽에 5개 분절로 된 진행 표시를 둠. 완료는 노랑, 남은 부분은 옅은 회색/파랑으로 표현하고 숫자는 작은 보조 정보로 한정. 텍스트만으로 된 `0/5 완료` 문장은 제거.
- 날짜 선택 왼쪽에 짧은 `Undo` 버튼. 왼쪽을 향한 뒤로가기 형태의 화살표/chevron을 사용하고 원형 회전·리로드 아이콘은 사용하지 않음.
- Undo가 없는 첫 화면과 방문 완료 후 Undo 가능한 화면을 함께 보여줌. 전체 일정 시각/순서는 변경하지 않으며 방문 완료 후 다음 장소만 이동.
- `여기부터 시작`의 표시 문구를 `Start here`로 변경. 작은 재생 아이콘, 낮은 글자 굵기, 프로젝트의 흰색/파스텔/남색 테두리·작은 그림자 표현으로 구성.
- 지출 상세는 선택한 세 번째 안의 도넛+분류+누적 구조를 유지하되 글자/도넛 크기를 절제. 원래 누적 경비에 포함된 사전구매를 별도 합계처럼 더하지 않음.

## 근거·경계

공통 컴포넌트는 `src/app/ui/trip-context.js`와 `src/styles/trip-context.css`, 일정 계획의 연결 위치는 `Travel.html`의 `[data-trip-context]`다. 실제 현재 코드는 목업용 맥락으로 읽었으며 이 단계에서 수정하지 않는다.

기준 데이터는 가상 예시다. 현재 날짜는 Asia/Seoul 기준 2026-11-01(일). 예시 여행명은 사용자가 언급한 `1000일 순천`, 기간은 2026-10-31(토)~11-01(일), 이날 지출 44,000원/2건 = 식비 32,000원 + 교통 12,000원. 누적 286,800원/9건 안에 사전구매 195,600원이 포함된다. 날짜·장소·금액을 앱에 고정하지 않는다.

기존 원안 둘을 명시적으로 선택해 조합·수정해 달라는 요청에 따라 단 한 번의 I2I 합성 목업을 만든다. 이번 생성 결과를 다음 호출에 반복 입력하는 연쇄 편집은 하지 않는다. 정확한 입력 역할·원본 경로·프롬프트·SHA256은 생성 기록에 남긴다.

메인 1번·지출 3번 선택 자체는 다시 묻지 않는다. 새로 추가하는 여행 정보/진행 표시/Undo/Start here 조합은 이 목업에서 보여준 뒤 구현 전에 확인한다. 사용자 지침: “해당 목업이 없는 경우에는 구현하지 말고 사용자에게 먼저 묻는다.”

## 구현 후 갱신 · 2026-11-01

사용자의 `구현ㄱㄱ` 이후 선택 조합을 로컬에 구현했다. 이어진 테두리·그림자·색상 피드백으로 카드 바탕은 흰색, 윤곽은 남색, 현재 장소 카드의 작은 오프셋 그림자는 브랜드 노랑으로 정리했다. 진행률·기간·Start here는 중성 회색과 흰색을 사용한다. 새로운 이미지 생성은 하지 않았으며 원본 목업·프롬프트는 보존한다. 실제 화면 비교와 검증 결과는 [구현 QA](../../qa/20261101-today-refinement-implementation/design-qa.md)에 기록했다. 운영 배포는 실행하지 않았다.
