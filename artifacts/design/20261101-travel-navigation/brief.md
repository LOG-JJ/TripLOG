# 여행 하단 메뉴 통합 목업

2026-11-01 · Asia/Seoul

사용자가 ‘오늘의 여행·예약 지갑·여행 도구’를 별도 하단 메뉴에 묶고 일정을 일정 계획 직행으로 바꾸는 제안을 요청했다. 하단을 ‘개요·일정·여행·지출·리포트’ 5개로 유지하고 설정을 상단 톱니바퀴로 옮기는 방향 및 여행 내부 3개 탭 목업 제안에 ‘그래 그렇게해보자’로 응답했다.

이번 범위는 선택한 메뉴 구조를 보여주는 이미지 목업이다. 하나의 구성에서 오늘의 여행·예약 지갑·여행 도구 상태를 나란히 표시한다. 각 기능의 세부 UI는 기존에 승인한 화면·후속 수정 사항을 구현 기준으로 유지하고, 이번 생성물은 공통 탭과 하단바 구성 검토에 사용한다. 목업의 예시 예약·진행 상태는 운영 데이터가 아니다.

- 하단: 개요 / 일정 / 여행 / 지출 / 리포트
- 여행 내부: 오늘의 여행 / 예약 지갑 / 여행 도구
- 일정: 기존 일정 편집·일정 요약으로 직접 이동
- 설정: 상단 톱니바퀴
- 여행의 세 상태에서 공통 하단 여행 활성 표시 유지

T2I 1회, 입력 이미지 없음. 실제 호출 원본을 명시적으로 복사하고 SHA256을 대조했다. 앱 소스·운영 데이터·배포에는 변경하지 않았다.

이미지: [travel-navigation-three-tabs.png](travel-navigation-three-tabs.png). 최종 프롬프트·원본 경로·SHA256·크기는 [generation.json](generation.json), 프롬프트 본문은 [prompt.txt](prompt.txt)에 보존한다. 목업 검토 후 내비게이션 구현 범위를 확정한다.

## 구현 완료 · 2026-11-01

사용자의 ‘일단 이렇게 구현해보자’ 요청 이후 위 메뉴 구조를 로컬에 반영했다. 여행은 일반 페이지이며 세 기능을 탭으로 전환하고, 일정은 직접 이동한다. 기존 기능 본문·브랜드 자산을 유지한다. 선택 탭은 URL에서 복원하고 기존 상세 팝업·복귀 흐름을 연결했다. [실제 화면 비교와 QA](../../qa/20261101-travel-navigation/design-qa.md)에 결과를 기록했다. 운영 배포는 실행하지 않았다.
