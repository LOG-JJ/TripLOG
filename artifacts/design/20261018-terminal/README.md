# TripLOG 터미널 디자인

사용자가 기존 CLI를 쉽게 조작할 수 있는 실제 Windows Terminal / PowerShell용 화면을 요청했고, 이미지 생성 모델로 먼저 구성한 메뉴를 바탕으로 구현했다.

- 생성 방식: **T2I 1회**, 이미지 입력 없음. 기존 목업을 재입력하지 않음.
- 생성 시각: 2026-10-18 01:35 KST 시작.
- 최종 프롬프트와 반환 원본 경로: [generation.json](generation.json).
- 보존 이미지: [triplog-terminal-concept.png](triplog-terminal-concept.png).
- 원본과 보존본 SHA256: `A8F68B364FA0CE3544E5A91BE59A219B534D597E14E72C2EC954F77EB7B80B23`.

구현은 어두운 배경, 분홍색 TRIPLOG 문자 로고와 선택 메뉴, 하늘색 테두리, 노란색 금액·확인 버튼, 왼쪽 10개 메뉴, 여행 개요·4개 요약·일정·빠른 실행 구조를 따른다. 실제 터미널의 고정 문자 셀 안에서 Unicode 선과 ANSI 색상으로 표현하며, 생성 이미지 자체는 실행에 사용하지 않는다. 생성 이미지에 임의로 들어간 2025년 일정은 예시 파일의 2026-11-07~09로 교체했다.

기준 화면은 120열 × 38행이다. 80열 × 24행에서는 2개 패널을 압축하고, 60열 × 20행에서는 선택된 패널 하나를 표시한다. 더 작은 창에서는 입력을 유지하며 확대 안내를 표시한다. 버튼·글자 크기와 그림은 터미널 문자 셀과 사용자의 글꼴 설정에 맞춰 구현했다.

구현 코드: `cli/tui/`. 실행: `npm run terminal`, 예시: `npm run terminal:demo`.

실제 ANSI 출력 캡처와 동작 검증은 [QA 기록](../../qa/20261018-terminal/README.md)에 보관했다.
