# 지출 화면 디자인 기준

## 현재 기준: 기존 TripLOG 톤으로 보정

사용자 피드백에 따라 아래 초기 목업의 독립적인 분홍/파랑 테마는 기존 앱 디자인으로 대체했다. 기존 로고, 흰 배경, `--rd-yellow`/`--rd-blue`/`--text` 토큰, 짙은 테두리와 작은 오프셋 그림자를 공유한다. 정렬된 목록과 입력 기능은 유지한다.

- 결제 금액 행 62px → 46px, 숫자 32px → 22px, 통화 선택 48px → 42px.
- 금액과 통화를 하나의 테두리로 묶고, 파란 포커스 링 대신 옅은 노란 배경으로 강조한다.
- 카테고리는 가로 아이콘/텍스트의 44px 버튼으로 축소하고 선택은 노란색으로 통일한다.
- 폼 간격은 PC 14px/모바일 12px, 데스크톱 팝업은 내용 높이에 맞춰 큰 하단 빈 공간을 없앤다.
- 빈 금액에는 환율만 안내하고, 환율이 없을 때는 ‘0원 환율’ 대신 입력 안내를 표시한다.

현재 화면: `expense-ui-amount-compact.png`, `expense-ui-editor-compact.png`, `expense-ui-editor-compact-mobile.png`.

## 화면과 디자인 토큰

- 기록 화면: 제목/여행 정보/주요 작업 → 하나의 예산 요약 영역 → 검색/카테고리/정렬 → 전체/사전구매/여행 중 → 날짜·내용·카테고리·결제 수단·금액·수정 열.
- 추가 화면: TripLOG/닫기 → 제목/영수증 → 결제 금액/통화/원화 환산 → 내용 → 3열 2행 카테고리 → 여행 일정/결제일 → 카드/현금 → 메모/결제한 사람 → 저장 후 계속/지출 저장.
- 배경 #f7f9fc, 화면 #ffffff, 본문 #101c3d, 보조 글자 #617394, 테두리 #dce4ef.
- 강조 분홍 #ff4b96, 주요 버튼 노랑 #ffe135, 보조 버튼 파랑 #e6f2ff, 선택 파랑 #1474dd.
- Pretendard: 제목 28–32px/750, 총액 28–32px/750, 입력 금액 32px/700, 항목명 15–16px/550, 표 금액 16–17px/700, 보조 정보 13–14px/400–500.
- 카드/입력 테두리 1px, 큰 화면 모서리 22px, 요약 14px, 입력/선택 10–12px, 테이블 행 구분선 #e8edf4. 진한 오프셋 그림자는 사용하지 않음.
- 기존 Phosphor 선 아이콘 사용. 금액은 tabular-nums와 오른쪽 정렬. 기본 터치 영역 44px 이상.
- 모바일: 요약에서 총액을 우선 배치, 목록의 열을 날짜/내용/보조 정보/오른쪽 금액으로 재배치, 검색은 한 줄, 추가 버튼은 하단 접근 가능. 추가 창은 전체 높이와 고정된 하단 저장 영역.

## 실제 기능과 데이터에 필요한 차이

- 목업의 샘플 연도/날짜/건수/금액은 실제 여행 및 기록에서 계산한다.
- 목업 상단의 알림 아이콘 대신 사용자가 요구했던 동기화 버튼과 기존 더보기 메뉴를 유지한다.
- 실제 분류 체계의 항공 지출은 교통으로 유지한다.
- 환율 수정, 숙박일별 분할, 메모/결제한 사람, 영수증 검토, 수정/삭제/취소 상태는 같은 입력 컴포넌트 체계로 확장한다.
- 데이터와 동작을 유지하는 실제 HTML/CSS 구현이며 이미지를 화면 배경으로 사용하지 않는다.

## 검증 기록

구현 완료 후 목업과 실제 화면의 배치·색상·글자·간격·아이콘·모바일 대응을 비교하고, 추가/연속 추가/수정/필터/정렬/원화/외화/영수증 전달/숙박 분할을 확인한다.
