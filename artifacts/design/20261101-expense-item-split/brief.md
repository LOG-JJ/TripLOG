# 지출별 분담 금액·비율 편집 목업

2026-11-01 · Asia/Seoul

사용자 요청: 지출 내역에서 각 지출을 수정할 때 사람별 분담 금액과 비율도 수정할 수 있도록 이미지 목업 제작.

## 공통 범위

- 지출 한 건에만 적용할 분담 설정. 실제 결제자(payer)와 비용 부담 대상·분담액을 구분한다.
- 균등 / 금액 / 비율 입력 방식. 편집 중인 방식은 입력칸으로, 환산된 다른 값은 보조 정보로 구분한다.
- 예시 지출 120,000원, 가상 동행 JJ/JH/민지. 금액 60,000/36,000/24,000원은 비율 50/30/20%에 대응한다.
- 미완료 예시는 50/30/10%=90%, 108,000원 배분, 12,000원·10% 미배분이다. 합계 불일치가 보이고 저장은 비활성인 상태를 탐색한다.
- 기존 수정창과 정산의 항목별 분담 모델을 기반으로 한 개념이며, 현재 코드의 `settlement.itemSplits`는 equal/custom 금액 분담을 보유한다. 새 비율 편집의 저장·반올림·총액 변경·외화·환불 계약은 구현 전에 확정해야 한다.
- 기존 여행 멤버를 대상으로 하며 동행 생성이나 다중 결제자 기능을 추가하는 요청으로 확대하지 않는다. 다른 지출에 자동 적용하지 않는다.

## 표시 순서

1. `inline-amount.png`: 기존 수정창에 금액 입력을 통합한 구성.
2. `focused-sheet.png`: 별도 분담 시트에서 비율을 편집해 수정 중인 지출에 적용하는 구성.
3. `visual-ratio.png`: 비율 바와 미배분 표시를 둔 구성 및 합계 미충족 상태.

각 결과는 독립적인 T2I 1회로 생성했다. 기존 스크린샷·목업·생성 결과를 이미지 입력으로 보내지 않았다. 세 이미지의 표시 순서는 이 대화에 실제로 출력된 순서다. 정확한 호출 원본, 최종 프롬프트, 크기, SHA256은 [generation.json](generation.json)에 기록했다. 각 원본을 명시적으로 복사하고 SHA256 일치를 확인했다.

이번 단계는 목업만 제작했다. 앱 소스·운영 데이터·배포에는 변경하지 않았다. 사용자가 방향을 선택한 뒤 필요한 입력·합계·정산 연동 동작을 정리한다.
