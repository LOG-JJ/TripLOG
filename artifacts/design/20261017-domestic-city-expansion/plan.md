2026-10-17 작성. 범위는 전국의 시 단위 목적지를 누락 없이 포함하고, 현재의 순천 기준 손그림 톤을 유지하는 것이다. 현행 시 단위 85개에 종전 광주 도시권 1개와 기존 군·섬·제주도 전체 권역 9개를 보존해 **국내 95개 목적지 전부에 PC·모바일 전용 그림을 연결**한다. 기존 그림 15쌍을 유지하고 **80쌍, 총 160장**을 새로 제작한다.

기초자치단체인 시 75개, 제주 행정시 2개, 특별시·광역시·특별자치시·통합특별시 8개를 포함한다. 자치구·일반구·읍면동은 별도 도시 수에 넣지 않는다. 수원·용인·고양·창원·화성의 특례시 표기는 같은 도시의 별칭으로 관리한다. 군 전체 확장은 이번 시 단위 전수 범위에 포함하지 않으며, 이미 등록된 군과 섬은 유지·완성한다.

**대표 소재 선정 방식**

전국 시 포함 여부는 행정명부로 결정한다. 관광 인지도와 무관하게 모든 시를 제작 대상에 넣는다. 그림의 소재는 [문체부·한국관광공사 한국관광 100선](https://www.mcst.go.kr/site/s_notice/press/pressView.jsp?pSeq=21611), [경기관광공사 관광 가이드북](https://www.ggtourmap.or.kr/fileUpload/2025_%EA%B0%80%EC%9D%B4%EB%93%9C%EB%B6%81_%ED%95%9C%EA%B8%80_web_1.pdf), 각 시의 공식 문화관광 자료에서 고른다. 이 자료들은 도시별 관광객 순위로 사용하지 않는다. 95개 항목의 개별 근거는 체크리스트에 연결했다.

한 그림에는 주인공이 되는 지형이나 건축물 하나와 보조 요소 한두 개를 넣는다. 작은 모바일 화면에서 지역 차이가 보여야 한다. 대표 장소와 도시의 관계는 확인했고, 최종 프롬프트를 만들기 직전에 공식 사진으로 건물 외형·색·지형·계절을 대조한다. 관광지 이름만으로 건물 구조를 상상해 확정하지 않는다.

| --- | --- |
| 수원·경기 광주·오산 | 수원화성의 성문과 평지 성곽 / 남한산성의 산능선 / 독산성·세마대 |

**유지할 그림 톤과 규격**

현재 [국내 그림 모음](../trip-scenes-redraw-20261004/contact-korea-landscape.png)과 [모바일 적용 비교](../trip-scenes-redraw-20261004/comparison-canonical-390.png)를 육안 기준으로 삼는다. 승인된 순천 [가로 원본](../trip-header-mobile-20261004/assets-original/kr-suncheon.png)과 [모바일 원본](../trip-header-mobile-20261004/assets-original/kr-suncheon-mobile.png)은 형태와 질감 비교에 사용한다.

- 짙고 또렷한 손그림 외곽선, 옅은 하늘색·녹색·모래색, 절제한 연필 질감을 유지한다.
- 사진형 풍경, 강한 입체 렌더, 두꺼운 수채화 번짐, 큰 글자·로고·UI는 넣지 않는다.
- 주 피사체를 오른쪽에 두고, 왼쪽 경계는 자연스러운 불규칙 실루엣과 투명 여백으로 처리한다.
- 그림은 오른쪽과 아래 테두리 안쪽까지 연결한다. 주요 피사체 전체가 화면 안에서 읽혀야 한다.
- PC는 **800×480, 5:3**, 모바일은 **480×600, 4:5** 투명 WebP로 납품한다. 원본 PNG는 따로 보존한다.
- 모바일은 세로 구도를 별도 제작한다. 가로 그림의 단순 잘라내기로 대신하지 않는다.
- 두 버전은 같은 랜드마크·계절·색감을 사용한다. 기존 정보 왼쪽·삽화 오른쪽 배치를 유지한다.

생성 기본은 **T2I, 이미지 입력 없음**이다. 기존 자산의 특징을 텍스트로 명세하고 결과를 기준 그림과 나란히 비교한다. 사용자가 특정 원본의 이미지 참조를 명시적으로 요청하는 경우에만 I2I로 전환하며, 그 경우에도 고정 기준 원본만 사용하고 새 도시 결과를 다음 도시 입력으로 이어 쓰지 않는다.

가로형 공통 프롬프트 초안은 다음과 같다. 도시별 주제와 구도는 제작 직전에 확정한다.

> Create a standalone destination illustration of [CITY], showing [ONE VERIFIED MAIN SUBJECT] with [ONE OR TWO SUPPORTING ELEMENTS]. Use crisp dark hand-drawn outlines, pale flat sky blue, green and sand yellow colors, and modest pencil texture. Compose a readable landscape in a 5:3 frame for an 800 × 480 transparent asset on the right side of a travel header. Keep the main subject comfortably inside the frame. Leave a quiet transparent upper-left and a natural irregular left silhouette. Let the painted scenery meet the right and bottom canvas edges. Artwork only, with no text, logos, UI or border. No input images.

모바일형에서는 4:5·480×600을 명시하고, 좁은 그림 영역에서 주 피사체를 크게 읽을 수 있도록 별도 구도를 지시한다. 이 프롬프트는 미실행 초안이며 실행 시 도구에 보낸 최종 문자열을 따로 기록한다.

**제작과 적용 순서**

| 단계 | 작업 | 새 이미지 수 | 완료 조건 |
| --- | --- | ---: | --- |
| 0 | 공식 명부·95개 목적지 ID·별칭·소재 확정 | 0 | 공식 시 85개 누락 0, 중복 0 |
| 1 | 인천·수원·보성·울릉도 표본 제작 | 8 | 도심·건축·농경·해안 네 유형이 현재 톤과 일치 |
| 2 | 나머지 기존 미전용 11곳 제작 | 22 | 기존 국내 30곳 모두 전용화 |
| 3 | 세종·충북 3시·충남 8시 추가 | 24 | 현재 비어 있는 충청권 시 목록 완성 |
| 4 | 경기 미등록 27시 추가 | 54 | 경기 28시 전부 전용화 |
| 5 | 강원 4·전북 4·전남권 2·경북 7·경남 6·제주 2·통합특별시 1 추가 | 52 | 나머지 26개 신규 목적지 전용화 |
| 합계 | 기존 누락 15곳 + 신규 65곳 | **160** | 국내 95개 전부 PC·모바일 전용 그림 |

표본 8장은 전체 160장에 포함한다. 단계 3~5의 순서는 작업량을 나누기 위한 것이며 후순위 도시도 필수 제작 대상이다. 본 제작은 5~10개 목적지씩 나누어 소재·톤·가독성을 검수한 뒤 다음 묶음으로 진행한다. 재생성 시안은 최종 활성 파일 수에서 제외한다.

기존 국내 30장 총 용량은 2,469,588바이트다. 같은 평균 용량을 가정하면 새 160장은 약 **13.2 MB**의 배포 자산이 된다. 이는 계획용 추정이며 실제 압축 결과로 갱신한다. 한 화면에서 필요한 이미지 한 장만 요청하고 도시 그림을 앱 설치 필수 캐시에 포함하지 않는 현재 방식을 유지한다.

국가가 한국인지 먼저 확인하는 기존 규칙을 유지한다. 여행 제목으로 목적지를 추론하지 않고, 여러 도시가 함께 입력된 여행은 공통 그림을 사용한다. 공식명·역사명·통용 별칭과 화면 표시명을 분리해 관리한다.

**파일 연결과 검증**

새 자산은 기존 파일을 덮어쓰지 않는 `src/assets/trip-scenes/cities/v5/`를 제안한다. `src/app/data/destination-scenes.js`의 목적지·전용 여부·버전 경로, `src/app/shared/destination-scenes.js`의 별칭·지역 관계를 함께 갱신한다. 실제 카탈로그가 참조한 파일만 배포 목록에 포함되므로 파일 복사만으로 완료할 수 없다.

각 생성 호출의 정확한 원본 경로, 최종 프롬프트, T2I/I2I 방식, 입력 이미지 유무, 원본·저장본 SHA256, 출력 크기와 선택 여부를 기록한다. 원본과 기록은 `artifacts/design/날짜-주제/`, 작업 스크립트·전체 캡처는 `artifacts/tmp/날짜-주제/`, 완료 검증 요약·대표 캡처는 `artifacts/qa/날짜-주제/`에 둔다. 최신 파일 검색으로 원본을 추정하지 않는다.

1. 공식 명부 85개와 계획·런타임 카탈로그의 지역·시명 집합을 대조하고 누락·중복이 0개인지 확인한다. 종전 광주 도시권과 기존 군·섬 9개는 별도 보존 집합으로 확인한다.
2. 95개 국내 목적지 모두 `dedicated`가 참이고 PC·모바일 파일이 존재하며 정상 디코딩되는지 검사한다. 최종 전체 카탈로그는 해외 300곳을 합친 395곳, 공통 테마 10쌍 포함 활성 그림은 810개다.
3. 별칭, 동명이인 도시, 신·구 행정명칭, 제주 부모지역 관계를 검증한다. 광주 테스트는 명확한 canonical 입력을 사용하고 모호한 단독 이름 테스트를 별도로 둔다.
4. 95개 목적지를 320·390·599·1440px에서 검사한다. 767/768px 전환점과 599/600px 경계, 613px 중간 폭, PC 패널, 긴 여행명도 확인한다. 실제 채색 픽셀의 하단·우측 공백, 테두리 연결, 피사체 잘림을 비교한다.
5. 이미지 실패·미캐시 오프라인·온라인 복귀, 필요한 한 장만 요청하는 동작과 48파일 캐시 한도를 확인한다.
6. `node tests/destination-scenes-regression.js`, `node tests/trip-scene-art-browser-regression.js`, `node tests/trip-header-browser-regression.js`, `npm run prepare:sync` 후 `node tests/trip-scene-cache-browser-regression.js`, `npm run artifacts:check`, `npm run test:source`를 실행한다. 전체 연결 완료 시 `npm test`와 `npm run build`를 수행하고 생성된 빌드 지문도 검토한다.

기존 테스트의 서귀포→제주 지역 기대와 평창→공통 산악 기대는 새 전용 그림에 맞게 분리한다. `tests/fixtures/trip-header.js`, `tests/destination-scenes-regression.js`, `tests/trip-header-browser-regression.js`, `tests/trip-scene-art-browser-regression.js`의 fixture·카운트·표시명 입력도 함께 갱신한다. 테스트 산출물은 공통 artifact helper와 `TRIPLOG_ARTIFACT_RUN`으로 관리한다.

이번 계획 자료를 검사한 결과 공식 명부 85개와 계획의 지역·시명 집합이 일치하고 누락·추가·중복은 0개였다. 전체 계획은 95개 고유 ID이며, 기존 30개 항목이 모두 보존되고 사람용 체크리스트도 95행으로 일치한다. 신규 등록 65개·새 제작 80쌍·160장의 산수와 JSON 파싱을 확인했다. `npm run artifacts:check`, `npm run test:source`, 현재 자산에 대한 `node tests/destination-scenes-regression.js`가 통과했다. 실제 신규 이미지 품질과 운영 반영 여부는 이후 제작·구현 단계에서 확인한다.

배포 요청이 있을 때 현재 저장소 지침의 Git 커밋·푸시 → 연결 자동 배포 절차를 따른다. 로컬 검증 완료, 푸시 완료, 운영 파일 확인을 각각 구분한다.
