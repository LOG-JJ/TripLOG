# 이름·주소 편집 하단 시트 목업

2026-10-27. 사용자 요청에 따라 이름·주소 편집 시트를 코드에 반영하고 격리된 브라우저에서 검증했습니다. 운영 배포는 진행하지 않았습니다. 비교 결과는 `artifacts/qa/20261027-place-edit-sheets/design-qa.md`에 보관합니다.

검토 대상은 이름·주소 변경 버튼의 아이콘 내부 배지 제거, 이름 변경의 간결한 입력 하단 시트, 주소 변경의 검색·결과·위치 확인 하단 시트입니다. 좌·중·우 세 화면으로 제안합니다. 다섯 액션의 색상 채움과 주요 노란 버튼이라는 방향을 유지합니다.

실제 구현 시 기존에 합의한 상단 X 왼쪽 Day·날짜, 공식 구글맵 아이콘, 컬러 소분류, 시작·종료 시간 두 필드, 메모·첨부 보존을 유지합니다. 생성 이미지의 주변 화면 단순화, 예시 사진·주소·검색 결과는 데이터나 추가 기능의 확정으로 해석하지 않습니다.

기존 이미지를 입력하지 않은 T2I 한 회로 생성했습니다. 최종 프롬프트는 `prompt.txt`, 원본 경로·SHA256·생성 시각은 `generation.json`에 보관합니다. `place-edit-sheets.png`는 도구가 반환한 정확한 원본에서 복사하고 해시를 대조했습니다. 사용자가 다시 첨부해 구현을 요청한 이미지와도 SHA256이 일치합니다.
