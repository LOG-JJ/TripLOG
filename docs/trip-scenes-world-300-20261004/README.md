# 해외 300곳 전용 여행지 그림 — 2026-10-04

**그림 제작·연결과 로컬 검증을 완료했습니다.** 해외 관광 목적지 300곳에 각각 PC·모바일 전용 그림이 연결돼 있습니다. 운영 반영 결과는 아래 배포 기록에서 별도로 확인합니다.

기존 해외 83곳에 217곳을 추가합니다. 기존 83곳 중 전용 그림이 없던 25곳도 새로 제작하므로 이번 제작은 242곳 × PC·모바일 2종 = **484장**입니다. 국내 30곳은 유지하며 최종 목적지 목록은 330곳, 전용 그림은 국내 15곳과 해외 300곳을 합친 315쌍입니다. 공통 테마 10쌍을 포함한 활성 파일은 650개입니다.

통계상 방문객 순위가 아니라 세계 관광 목적지를 폭넓게 다루기 위한 편집 목록입니다. 도시·소도시·섬·지역을 구분하며, 몰디브·발리·오아후·카파도키아 등을 다른 도시의 별칭으로 바꾸지 않습니다. 국가와 도시 이름을 함께 사용해 그림을 선택하고 저장된 여행 정보는 수정하지 않습니다.

- `selection.json`: 기존 83곳과 신규 217곳의 범위 및 권역별 선정 목록.
- `batch.json`: 이번 제작 242곳의 정확한 식별자, 한글·영문·현지 별칭, 목적지 분류, 대표 풍경, 참고 출처.
- `jobs/`: 이미지 484개 각각의 확정 프롬프트, 이미지 입력, 원본·저장 경로, 크기.
- `assets-original/`: 정확한 생성 원본 PNG, 실제 프롬프트, 생성 도구 원본 경로와 원본·저장본 SHA256.
- `prepared.json`·`progress.json`: 웹용 이미지의 검증·변환 완료 수와 남은 작업.
- `base-catalog.json`: 이번 작업 직전의 113곳 목록.
- `country-aliases.json`: 국가·지역 93개 코드의 한글·영문 인식 정보.
- [국가별 300곳 목록](catalog-index.md)·`coverage.json`: 런타임에서 생성한 전체 해외 목적지, 별칭, PC·모바일 그림 경로와 준비 상태. `node docs/trip-scenes-world-300-20261004/write-catalog-index.cjs`로 갱신합니다.

생성 방식은 사용자가 명시적으로 요청한 현재 순천 그림의 감성을 이어가는 I2I입니다. 각 PC 그림은 승인된 `kr-suncheon.png`만, 모바일 그림은 승인된 `kr-suncheon-mobile.png`만 참조합니다. 새로 생성된 다른 도시 그림을 참조하는 연쇄 I2I는 사용하지 않습니다. 새로운 디자인 방향을 탐색하는 작업이 아니며, 여행 정보 왼쪽·삽화 오른쪽의 기존 배치와 줄인 제목 크기를 유지합니다.

원본은 호출이 반환한 정확한 파일에서 저장하고 SHA256 일치를 확인합니다. 웹용 출력은 800 × 480과 480 × 600의 투명 WebP이며, 기존 파일을 덮어쓰지 않는 `src/assets/trip-scenes/cities/v4/` 경로를 사용합니다. 도시 그림은 앱 설치 필수 캐시에 포함하지 않고 필요한 화면에서 요청합니다.

484장 원본·프롬프트·생성 경로·SHA256, 활성 이미지 650개, 315개 전용 목적지의 1,260개 화면 검사가 통과했습니다. 헤더 반응형·여행 선택·오프라인·캐시 검사와 `npm test`, `npm run build`도 통과했습니다. 새 WebP는 43,709,772 bytes이며, 설치 시 모든 도시 그림을 내려받지 않습니다. 자세한 근거는 [검증 기록](design-qa.md)과 [실제 모바일 화면 모음](rendered-highlights-390.png)에 있습니다.
