# TripLOG 저장·실시간 협업 구현 계획

작성: 2026-09-19 KST · 상태: 계획만 작성

현재 구현 기준은 아래 두 문서다.

1. [실시간 공동 여행 서비스 설계](realtime-collaboration-plan.md): 제품 동작, 항목별 데이터 모델, 자동 병합, 명령 API, 실시간 수신·오프라인 재연결, 권한, 단계별 구현 계획.
2. [서비스 구현·출시 상세 명세](service-readiness-spec.md): API 계약·큐 상태 전이, 여행 시간·금액·정산·파일의 규칙, 개인정보·접근성, 백업·운영, 작업 목록·의존성·출시 게이트·위험 관리.

기존에 확인한 7개 유실 경로의 회귀 테스트와 원본 보존 요구사항은 그대로 유지한다. 최종 구현은 여행 전체 스냅샷 충돌 시 멈추는 방식에서 항목·필드 단위의 자동 병합과 실시간 협업으로 확장했다.

일반 화면의 수동 동기화 버튼·메뉴는 자동 동기화 검증 후 저장 상태 표시로 교체한다. 로컬 저장 뒤 전송, 원격 변경 수신, 연결 복구와 재시도는 자동이며, 지속적인 오류에만 같은 안전한 경로의 ‘다시 시도’를 제공한다. [자동 동기화 실행 정책](service-readiness-spec.md#자동-동기화-실행-정책)에 실행 조건·상태·시험 기준을 정의했다.

복구 작업은 사용자 요청으로 중단했다. 이 계획 작성 과정에서는 앱 코드·운영 DB·배포를 변경하지 않았다.
