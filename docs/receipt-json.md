# AI 영수증 결과 붙여넣기

앱에는 AI 모델이나 API 연결이 없습니다. 외부 AI에서 영수증을 읽은 결과를 JSON으로 가져옵니다.

별도로 복사해서 쓸 [AI용 프롬프트](receipt-ai-prompt.txt)도 제공합니다. 앱에서 복사하면 현재 여행 기간과 결제자 목록까지 자동으로 포함됩니다.

1. **지출 추가 → 텍스트 · 영수증**을 엽니다.
2. **AI용 프롬프트 복사**를 누르고 외부 AI에 영수증과 함께 전달합니다. 현재 여행 기간과 결제자 목록이 포함됩니다. 복사가 차단되면 펼쳐진 프롬프트를 직접 복사합니다.
3. AI가 출력한 JSON 객체 전체를 **AI 결과 붙여넣기**에 넣습니다. `json` 코드 블록째 붙여넣어도 됩니다.
4. **붙여넣은 정보 확인 → 지출 정보에 적용**을 누릅니다.
5. 채워진 지출 폼을 확인하고 **지출 저장**을 누릅니다. 적용만으로는 저장되지 않습니다.

한 번에 지출 한 건을 처리합니다. 금액·통화·내용·결제 방식과 기록 일자를 확인할 수 없으면 확인 화면에서 입력합니다. 메모, 결제자, 실제 결제일, 환율, 숙박 기간은 지출 폼에 함께 적용됩니다. 기존 지출 수정에 숙박 기간을 가져오는 것은 지원하지 않습니다.

```json
{
  "description": "교토 식당 · 점심",
  "paymentDate": "2026-09-25",
  "expenseDate": "2026-09-25",
  "amount": 2400,
  "currency": "JPY",
  "category": "식비",
  "paymentMethod": "cash",
  "note": "2인 식사",
  "payerKey": null,
  "exchangeRate": null,
  "checkIn": null,
  "checkOut": null
}
```

금액은 현지 통화의 최종 결제 총액입니다. 사전구매는 `expenseDate`에 `__pretrip__`을 씁니다. 날짜는 `YYYY-MM-DD`, 알 수 없는 값은 `null`입니다. 환율은 JPY·VND만 100단위당 원화, 나머지는 1단위당 원화입니다. 환율이 없으면 폼의 환율을 사용하므로 저장 전에 확인합니다. 결제자가 없으면 폼의 현재 결제자를 유지합니다. 숙소는 전체 숙박 총액과 체크인·체크아웃을 입력하면 기존 숙박 분할 기능으로 저장합니다.

지원 항목 외 키, 잘못된 날짜·금액·통화, 여행에 없는 결제자, 여행 기간 밖의 기록 일자는 오류로 안내합니다. 붙여넣은 내용은 실행하지 않고 JSON 데이터로만 해석합니다.
